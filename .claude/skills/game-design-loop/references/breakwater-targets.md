# 防波堤 の目標曲線

`npm run sim -- breakwater 30 1,3,4,6,9` の出力と対で更新する。行は島 × 方策、列は★の分布（★0 は負け）。

方策は 3 つ。`idle` は何もせず潮を進める。`random` は各駒が無作為に動いて行動する。`greedy` は駒の順番 6 通りを試し、各駒が 1 ターン先の結果で最善の（移動・行動）を選ぶ。ターンをまたぐ読みはしない。プレビューと「戻す」を使う人は greedy の近くに来る想定。

## 目標

| 島 | idle / random の勝率 | greedy の ★3 |
| -- | -------------------- | ------------ |
| 1〜3 | 25% 以下 | 70〜80%（ルールを覚える島） |
| 4〜6 | 15% 以下 | 30〜40% |
| 9  | — | 10〜20% |

## 数値と効き方

| 数値 | 値 | 効き方 |
| ---- | -- | ------ |
| 敵の体力 | 基本値 + `floor((島 - 1) / 3)` | 増援の数だけを増やしたときは、島 6 の greedy ★3 が 57% のまま動かなかった。体力を足すと 33% に下がった |
| 増援 | 1 + (潮 2 以降 +1) + (島 2 以降、潮 3 以降 +1) + (島 4 以降、偶数の潮 +1) + (島 6 以降、潮 3 以降 +1) | |
| ゴウラ（体力 3・2 ダメージ）の出現率 | `min(0.12 + 島 × 0.03, 0.3)`（島 2 以降か潮 3 以降） | |
| 家 | 6 軒。★3 は 5 軒以上、★2 は半分以上 | |
