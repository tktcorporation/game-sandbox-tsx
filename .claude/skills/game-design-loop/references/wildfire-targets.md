# 延焼線 の目標曲線

`npm run sim -- wildfire 40 1,3,5,8` の出力と対で更新する。行は山（レベル）× 方策、列は★の分布。

方策は 3 つ。`none` は何もしない。`random` は作業員が空くたびに無作為なマスを掘る。`planner` は、風を重みにした最短経路で火が村へ届くまでの時間を、最も遅らせるマスを 1 つずつ掘り、村に接した火には放水する。

## 目標

| 山 | none の ★3 | planner の ★3 |
| -- | ---------- | ------------- |
| 1  | 5% 以下    | 70〜80%       |
| 3  | 5% 以下    | 45〜55%       |
| 5  | 0%         | 20〜30%       |
| 8  | 0%         | 10% 前後      |

狙いは 2 つ。何もしなければ村は燃える（掘る判断が要る）。同じ盤面でも掘る場所の良し悪しで結果が大きく変わる（random と planner の差）。

## 数値と効き方

| 数値 | 値 | 効き方 |
| ---- | -- | ------ |
| 風向き | 南・南東・南西のみ（北へは吹かない） | 東西・北向きを許すと、火が上辺で燃え尽きて none でも 15〜33% が★3 になった |
| 延焼倍率（風下 / 横 / 風上） | 2.2 / 0.65 / 0.2 | 横 0.8・風上 0.25 では planner でも山 5 以降の★3 が 0% |
| 燃焼ティック（草 / 森 / 村） | 2 / 5 / 6 | 1 / 3 / 4 では火が約 30 ティックで自然に消えた |
| 作業員の回復 | `2 + floor((山 - 1) / 3)` ティックに 1 人、最大 6 | 山が進むほど掘れる数が減る |
| 火元 | `2 + min(3, floor(山 / 2))` | |
