# 深淵採掘 の目標曲線

`npm run sim -- abyss 600` の出力と対で更新する。方策は「次の 1 枚で崩落する確率が閾値を超えたら引き返す」。列は店の買い方。

## 目標

- 平均得点が最大になる閾値が、0 と 1 の間（0.2〜0.35）にある。端にあると「必ず引き返す」か「行けるだけ行く」が正解になり、押し引きの判断が消える
- 何かを買う方策が、買わない方策の最大値を上回る。ただし買い物ごとに得意な閾値が違う（鉄兜は中庸、命綱は攻めた閾値で伸びる）

## 数値と効き方

| 数値 | 値 | 効き方 |
| ---- | -- | ------ |
| 酸素（1 潜行の最大枚数） | 12 | 8 では閾値 0.25 以上の結果がすべて同じになり、上限が先に効いて「行けるだけ行く」が最適だった |
| 深さ倍率 | 1–4 枚目 ×1、5–8 枚目 ×2、9 枚目以降 ×3 | |
| 鉄兜 / 命綱 / 探照灯 | 45 / 30 / 20 | 予備ボンベ（酸素 +3）は酸素上限に届かないため買う価値が無く、命綱に置き換えた |
