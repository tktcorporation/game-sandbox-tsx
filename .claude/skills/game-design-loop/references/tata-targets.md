# モンスターサバイバル 戦闘の目標曲線

`npx tsx scripts/sim/tata-battle.ts 150` の出力と対で更新する。列は突破した wave 数の分布、行は基準パーティ × 相性。

## 目標

| 基準パーティ                     | 有利                       | 中立                 | 不利                 |
| -------------------------------- | -------------------------- | -------------------- | -------------------- |
| 序盤（御三家 st1 + 石 st1）      | wave 3 が最頻、勝ち 0%     | wave 2〜3、勝ち 0%   | wave 2 が最頻        |
| 序盤 + 捕まえた 1 匹（st0）      | wave 3 が最頻、まれに 4    | wave 3               | wave 2〜3            |
| えさ後（st2 ×2 + st1）           | 勝ち 15〜25%               | 勝ち 0〜5%           | 勝ち 0〜5%           |
| 中盤（st2 ×3、power 3）          | 勝ち 60〜70%               | 勝ち 25〜35%         | 勝ち 10〜30%         |
| 終盤（st3 ×3、power 6）          | 勝ち 90% 以上              | 勝ち 95% 以上        | 勝ち 60〜75%         |

狙いは 3 つ。序盤は必ず負けるが wave 2〜3 まで見せる。有利属性を選ぶと中立より約 1 wave 先へ進む。終盤でも不利属性を選べば負けうる。

目標との差で残っているのは 1 つで、終盤の有利が中立を下回る。有利属性の種族プールに rarity 2 以下の tank が少なく基礎値が低いためで、種族データ側の分布の問題として次サイクルの候補にする。

有利・中立・不利の定義は `matchupOf`（`battle.ts`）で、画面の「ゆうり／ふり」札と sim の行が同じ判定を使う。有利は「テーマのどちらかに強く、どちらにも弱くない」、不利は「どちらかに弱く、どちらにも強くない」。

## 変更履歴

### サイクル 1：襲撃の属性テーマと wave の直列化

変更前は、同じ基準パーティならほぼ 100% 同じ wave で倒れ、中盤以降は属性に関係なく 100% 勝っていた。

| 変更                                                     | 理由                                                   |
| -------------------------------------------------------- | ------------------------------------------------------ |
| 襲撃をシードから事前生成し、主属性と副属性のテーマを持つ | 相手の属性が見えないと相性が判断に使えない             |
| 次の wave は前の wave の全滅か 14 秒の猶予で開く         | 時間だけで開くと全 wave が塊になり突破数が無意味だった |
| ダメージに 0.85〜1.15 の幅                               | 結果が決定的で再挑戦の余地が無かった                   |
| wave 倍率 0.22 → 0.45、ボス HP 120 → 95、よた HP 28 → 24 | 直列化で易しくなった分を戻し、終盤の段差を均す         |
| 突破数を「全滅させた wave の数」で数える                 | 時間経過で数えると生き残るだけで突破扱いになっていた   |

## おさんぽの目標

草むらを選ぶと、その属性のタタが出る割合が 7 割前後になる。属性ごとの種族数の違いで割合がぶれないこと。`npx tsx scripts/sim/tata-stroll.ts` で確認する。

### サイクル 2：草むらに属性を持たせる

変更前は 6 つの草むらが同じ処理を呼び、選択に差が無かった。草むらを属性ごとに 1 つずつにし、次の襲撃に有利な属性を画面に出して、対策を狙って歩けるようにした。

```

empty dex : fire   72%  water  70%  grass  69%  earth  73%  light  69%  dark   69%
60 owned  : fire   70%  water  71%  grass  70%  earth  68%  light  72%  dark   69%
```
