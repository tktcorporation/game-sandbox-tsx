# 診断で見つけやすい兆候

Step 0 の診断で当たりを付けるための一覧。各項目は「兆候」「なぜ面白さを削るか」「どの要素が欠けているか」の順に書く。

| 兆候                                                                   | なぜ削るか                                                                     | 欠けている要素   |
| ---------------------------------------------------------------------- | ------------------------------------------------------------------------------ | ---------------- |
| 複数のボタンが同じ関数を呼ぶ                                           | 数回で「どれも同じ」と学習され、以後の選択肢が信用されなくなる                 | 判断（差）       |
| 戦闘・生産がプレイヤー入力を受けない                                   | 見ているだけの時間になり、結果を自分のせいにできない                           | 動詞             |
| 敵の属性・構成がほぼ単一                                               | 相性の仕組みがあっても使う場面が無い                                           | 判断（非自明）   |
| ゲームが最適解を出すボタンを持ち、その基準が真の最適と一致する         | 考える理由が無くなる                                                           | 判断（非自明）   |
| 敵の wave が前の wave を待たずに来る                                   | 「wave」という区切りが実感できず、突破数が意味を持たない                       | フィードバック   |
| ルール説明の文章が画面にある                                           | 判断に要る情報が画面に無いことの印                                             | 情報             |
| 通貨が 3 つ以上あり、それぞれ 1 つの用途にしか使えない                 | 通貨どうしの緊張が無く、独立したページが並ぶだけになる                         | 判断             |
| タイマーで操作を遅らせるが、待つ間に考えることが無い                   | 放置ゲームの文法だけ借りて、通知や対人の理由が無い                             | 積み上がるもの   |
| 本家ジャンルの片側（攻められる・失う）が無いのに、防衛側の建物がある   | 防衛の配置が結果に一切効かず、半分のシステムが飾りになる                       | 帰結             |
| シミュレーション結果が 100% か 0% に集中する                           | 進行が曲線ではなく段差で、その区間では判断もレベルアップも効いていない         | フィードバック   |
| 発注・目標が数量しか要求しない                                         | 空間・時間・スループットの制約が無く、最適化する動機が生まれない               | 判断（非自明）   |
| 負けたときの画面が勝ったときと同じ場所へ戻る                           | 負けの原因も次の手も示されず、学習が起きない                                   | フィードバック   |
