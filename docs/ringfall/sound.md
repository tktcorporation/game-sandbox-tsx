# RINGFALL の音の決めごと

音は `src/ringfall/view/sfx.ts` の合図（cue）を `view/audio.ts` のミキサーで鳴らす。どれもその場で合成する（brief の「音」）。画面の決めごと（[ui.md](ui.md)）と同じく、先に枠を決め、検査がそれを測る。

`npm run sfx:ringfall` は、全部の合図をゲームと同じ経路でオフラインに書き出し、1 つずつ測る。音を足すか変えたら、これを通してから出す。

## 大きさは段で決める

聞こえ方の大きさは、合図ごとの一番大きい 400 ms を、放送の音量と同じ K 特性で測った値（LUFS）で比べる。ピークや 20 ms の RMS は、短い音と長い音で耳の感じ方とずれる。

合図はどれか 1 つの段に入り、段の幅に収める。段は `scripts/ringfall-sfx.mjs` の `TIERS` にある。

| 段 | 何か | LUFS |
| --- | --- | --- |
| big | 大きな瞬間：撃破、シールド破壊、離脱ジャンプ、上陸、結果 | -24〜-12 |
| shot | 自分の銃声 | -30〜-12 |
| hit | 当てた手応え | -36〜-26 |
| signal | 合図：気づかれた、増援、拾う、核の警報 | -42〜-20 |
| robot | ロボットとリオの音（決まった距離に置いて測る） | -44〜-20 |
| body | 自分の体：跳ぶ、着地、登る、被弾、回復の最中 | -42〜-26 |
| hand | 手元：リロード、弾切れ、箱、ジップラインの金具 | -46〜-32 |
| camp | 野営地の板 | -46〜-22 |
| air | 島の環境音：きしみ、機械、カモメ | -48〜-34 |

どの段にも入らない合図は検査で落ちる。新しい合図は段を決めてから足す。

### 先に聞こえるものが大きい

段の中でも、並んで鳴るものは順が決まっている（`UNDER`）。

- リロードと装填の音は、その銃の銃声より 4 LU 小さい
- 普通の命中は弱点の命中より 3 LU、撃破より 10 LU 小さい
- 壁登りは銃声より小さい
- 板の「選ぶ」は「買う」より小さい
- ロボットの足音は、同じロボットの射撃より 6 LU 小さい

## 大きさは `gain` で揃える

`play()` の `level` は音の大きさではない。同時に鳴る音の上限（パソコン 28、スマホ 14）を超えたときに、どれを止めるかを決める目安と、距離での減り方の起点に使う。

合図の大きさを段に合わせるときは、`gain` を渡す（`own()`、`ui()`、`me()` の最後の引数、`at()` の `gain`）。音の作り（周波数、長さ、重なり）は変えずに、全体を上げ下げする。

## 検査が見るもの

| 名前 | 見つけるもの |
| --- | --- |
| silent | 一番大きい 20 ms が -50 dBFS 未満 |
| NaN / clip | 壊れたサンプル、満杯の振幅 |
| tier | 段の幅の外の LUFS、段の無い合図 |
| under | `UNDER` の順が崩れたもの |
| voices | 80 発同時に撃ったあとに、上限を超えて鳴っている声 |

表には合図ごとの段、ピーク、LUFS、鳴り終わるまでの秒が出る。合図の多くは 1 発ごとに高さを少し変えるので、LUFS は回ごとに 1 LU ほど動く。段の端にいる合図は、端から離しておく。
