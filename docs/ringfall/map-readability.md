# 地図の見やすさ

島の地図・出撃の地図・地図の机・結果の日の地図・ミニマップを、画面サイズが変わっても見切れず、狭く感じないようにするための決めごと。画面の色や字の段は [ui.md](ui.md)。前線と陣地の意味は [island-v2.md](island-v2.md)。

参考にした他ゲームと、そこから採った仕組み:

| 参考 | 採ったこと |
| --- | --- |
| Clash of Clans / Into the Breach | 開いた瞬間に対象が枠に収まる（fit-to-content）と、端の余白 |
| Slay the Spire / FTL | 全体が一目で見える初期表示（地図の机・出撃・全体表示） |
| Pokémon GO | ピンチとホイールのズーム、ドラッグのパン、フィットより外へは出さない限界 |
| アークナイツ / Into the Breach | 画面外の目標への端矢印 |
| （共通） | セーフエリアと UI が重ならない余白。大きな作り直しより見切れと狭さを消す |

## 初期表示

| 画面 | 最初に映す範囲 |
| --- | --- |
| レイド中の地図（M） | 今いる地域（`Region.bounds`）。N で島全体 ↔ 地域 |
| 地図の机 | **島全体**（地域だけに切らない） |
| 出撃 | 島全体 |
| 結果の日の地図 | 島全体 |
| ミニマップ | 自分のまわり 180 m（従来どおり） |

フィットした枠の外側に約 110 m の余白を足す。端の拠点名・お隣の島の札がキャンバスの縁で切れないようにするため。

## ズームとパン

- 対象: レイド中の地図、地図の机（出撃は出発点のボタンが地図の上に載るので、フィットだけにして動かさない）
- ホイール／ピンチで拡大（最大 4 倍）。ドラッグでパン
- ダブルクリックでフィットに戻す
- パンの限界は「フィットした枠の中」——空の海だけを眺め続けられない
- 地域 ↔ 全体の切替、地図を開き直すときはフィットに戻す
- デスクトップで地図を開くと視点ロックを外し（一時停止にはしない）、閉じると戻す。ロック中はホイールがキャンバスに届かないため

## 画面外の名前と端矢印

以前は、枠の外にある拠点の名前を左右の端へ寄せて描いていた。地域表示なのに発射場や機械都市の名前が縁に積み上がり、見切れと狭さの主因になっていた。

今は:

- 枠の外の名前は描かない
- 枠の外の目標（自分・依頼の先・夜の印・来る遠征・脅威の拠点・地域表示時の前線）だけ、キャンバス端に矢印を出す

## レイアウトとセーフエリア

- 地図キャンバスの縦横比は、今映している枠の比（`--map-aspect`）に合わせる。箱だけ横長／縦長で中がレターボックスにならないようにする
- レイド中の地図はセーフエリアを避け、凡例の分を残して高さを取る
- 出撃の地図板は、高さ 100% と `max-width` が喧嘩して縦に空きが残らないよう、世界の縦横比から幅を決める

## 触らないもの

- プレイヤー向けの既存の文言・凡例の語
- 依頼板（**削除済み** 2026-11-24。別件）
- ミニマップの 180 m と、HUD の方位・端の脅威矢印の役割分担（地図の端矢印は地図を開いているときだけ）

```bash
CHROMIUM_PATH=/opt/google/chrome/chrome node scripts/ringfall-shots-map-fit.mjs AFTER
```
