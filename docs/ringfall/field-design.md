# RINGFALL のフィールドの作り方

場所（POI）を作るときと作り直すときの決めごと。測り方は `field.md`、ここは「何を目指して作るか」。

相手はロボットだけで、プレイヤー同士は戦わない。だから攻める側と守る側を釣り合わせる必要はなく、POI は「ロボットが守る場所に、プレイヤーが入り口を選んで攻め込む」形に作る（Valorant のサイト）。POI と POI の間の移動は、視線を切るものを途中に置いて渡れるようにする（Apex の POI 間の移動）。

## 寸法の物差し

ゲームの数字から決める。新しい場所もこの物差しで作る。

| 数字 | どこから | 作り方への意味 |
| --- | --- | --- |
| 目の高さ 1.6 m、しゃがみ 1.0 m | `PLAYER.eye` | プレイヤー用の低い遮蔽は 1.1〜1.3 m |
| ロボットが隠れる高さ 1.5 m | `COVER.tall` | 測定とロボットの遮蔽になるのは 1.5 m 以上 |
| 跳んで越える 2.9 m | `MANTLE.reach` | 2.9 m 以下は越えられる、それより高いと回り込む |
| よじ登る 6.2 m | `CLIMB.reach` | 2 階建ての屋根より上へは、階段か積んだ箱で道を作る |
| スプリント 7.6 m/s | `PLAYER.sprint` | 戦う区画では遮蔽と遮蔽の間を 8 m 以内（約 1 秒）にする |
| ロボットが戦闘中に見える距離 56 m | `field.md` | POI の中心を横切る 56 m 超の視線は、狙撃用の通り道として決めた所にだけ置く |

| 空間 | 幅・大きさ |
| --- | --- |
| 入口・屋内の通路 | 2.2〜4 m |
| 路地 | 5〜8 m |
| 通り | 10〜16 m |
| 中庭 | 25〜40 m 四方 |
| POI の中心部 | 半径 60〜90 m |
| 外周 | 中心部の外側 30〜60 m |
| POI 間の移動路 | 40〜60 m ごとに視線を切るもの |

## POI の型

1. 外周：中心部の外側に、岩・土手・車の群れ。入口に取り付く前の最後の遮蔽。
2. 入口：2〜3 本と裏道 1 本（広くて速い道、狭くて屋内を通る道、梯子や積んだ箱で上がる道）。どの向きから来ても、中心部へ別々の道が 2 本以上ある。
3. 中庭：島のように置いた遮蔽を 2〜3 群。中心を横切る長い視線は切る。
4. 中心部：金庫・核。行き止まりはここだけにする。
5. 高所：上がり口を 2 つ以上作り、上では身をさらす代わりに見下ろせる。


## 構造物と遮蔽の決めごと

同じような建物や同じ箱がたくさん並ぶと、特徴がなく手抜きに見える。遮蔽が増えても、それだけでは良くならない。

1. **大きな一体の構造物を先に置く。** その場所の役割がそのまま形になった構造物（管制壕と土盛り、給水塔と配管、アンテナの台座、積み込み場の屋根）を置き、その形が遮蔽と高所と通路を兼ねるようにする。小さな箱を並べて遮蔽を作るのは最後の手段。
2. **同じ形の構造物を 1 つの場所に 2 つ置かない。** 並べるのに意味がある時（長屋、コンテナの列、タンクの列）だけ並べてよい。並べる時も、1 つは壊す・開ける・高さを変えるなどして、どれか 1 つに目が行くようにする。
3. **細かい遮蔽が要る所は、その場所の物を使う。** コンテナ・木箱・車止めを使い回さない。題材から選ぶ（塩田なら畦と水門小屋、発射場なら防爆壁・ケーブルドラム・機材ラック、街なら停留所・植え込み・売店）。方角や区画ごとに変えてもよい。
4. **遮蔽は 1 個だけで置かない。** 2〜5 個の群れにして、通路の縁か入口の脇に置く。
5. **遠くから見分けられるシルエットを 1 つ持つ。** その場所で一番高い物が、2 番目より目立って高い（目安 +10 m）。

## 測る（`npm run variety:ringfall`）

上の決めごとが守れているかを、箱の配置から数える（`scripts/ringfall-variety.ts`、1 か所 1 秒弱。`--all` で全 POI）。触れ合う箱をつないで 1 つの「物」とし、床面積 60 m² 以上か、4 m 以上の高さで 4 m² 以上あるものを構造物、残りを細かい遮蔽とする。高さ 1 m 未満・面積 1 m² 未満の物（柱・手すり・地面の塗装）は数えない。`look:ringfall` も同じ数字を出し、基準と比べる。

| 指標 | 何を見るか | 目安 |
| --- | --- | --- |
| struct | ロボットの遮蔽点のうち、構造物に沿っている割合 | 70% 以上 |
| top | 細かい遮蔽のうち、一番多い 1 種類が占める割合 | 15% 以下 |
| kinds | 細かい遮蔽の種類の数 | 多いほどよい（割合と合わせて見る） |
| twins | 同じ形（床面積・高さ・箱の数・種類）の構造物の組の数 | 0。並べる意味がある時だけ。一覧を読んで判断する |
| generic | 細かい遮蔽のうち、全 POI の半分以上で使われている物の割合（どこにでもある物） | 25% 以下 |
| scattered | 細かい遮蔽のうち、自動配置（`scatterCover()`）が置いた割合 | 下げる。その場所のために置いた物を増やす |
| landmark | 一番高い構造物の高さと、2 番目との差 | 差 +10 m 以上 |

1 か所を指定すると、一番多い物とその位置、同じ形の構造物の組、ランドマークを並べて出す。直す場所はそこから探す。

数字は機械的な目安で、合格・不合格はない。役割が形から読めるか（遠くから見て何の施設か分かるか）は数字では測れないので、`look:ringfall` の画像で必ず確かめる。

読み取れること：

- **どの POI も細かい遮蔽の半分以上が自動配置。** 自動配置は全地域で同じ部品（車止め・車・パレット・土嚢）を使うので、generic と scattered が高い所ほど「どこも同じ」に見える。場所ごとに置く物を決めるか、自動配置の部品を地域・題材ごとに分けるのが一番効く。
- **機械都市（terminal / carpark / robotworks / highrise）は generic 69〜85%。** 道ばたの車と車止めがほとんど。
- **コンテナ置き場（yard）は同じ形の積み方が 18 組。** 題材上コンテナが並ぶのは正しいが、積み方の型が少ない。
- **管制センター（control）は作り直した方針どおり**、top 8%・generic 10%・twins 0。struct が 64% と低めなのは、題材に合わせて置いた細かい遮蔽が多いため。
- **燃料基地（fuel）・ロッジ（lodge）・追跡レーダー（radar）・コンテナ置き場（yard）は、飛び抜けて高い物がない**（差 +0）。

## 進め方

1. `npm run look:ringfall -- <POI> --base` で基準を取る（field と variety の数字も残る）
2. `npm run variety:ringfall -- <POI>` で、使い回している物・同じ形の構造物・ランドマークを確かめる
3. その場所の役割を一言で決め、それが形になる大きな構造物から置く（上の「構造物と遮蔽の決めごと」）
4. 箱だけで形を変える（入口・中庭・外周・高所）
5. `npm run look:ringfall -- <POI>` で、field と variety の数字と画面が狙った方へ動いたかを見る
6. 遊んで確かめ、ロボットの配置と一緒に詰める
7. 形が固まってから見た目（アセット）を整える

作業の手順は `.claude/skills/ringfall-field/SKILL.md` にもある。

### 管制センター（2026-11-27）

建物 1 つと散らばった箱だけだったのを、敷地として作り直した（`controlGrounds()`）。同じ形の箱を並べるのでなく、発射管制の施設の大きな構造物を置き、その形がそのまま遮蔽と高所になるようにした。

- 2.2 m の塀に開口を 4 つ：東門・南門・西門・北の崩れ
- 北西：耐爆の管制壕（`bunker()`）。3 段の土盛りの下に部屋があり、部屋から壕が掘られている。土盛りは段を登れて、壕は横から撃たれにくい通路になる
- 北東：給水塔（中を登れる鉄塔とタンク）と、宿舎の方へ延びる配管。配管は 12 m ごとに途切れていて、そこを渡れる
- 南西：追跡アンテナ。台座の上の皿と、周りの機器箱
- 南東：推進剤の積み込み場の屋根。下にタンクローリー 2 台。屋根へは東の階段か、ローリーの上から上がれる
- 細かい遮蔽も場所ごとに変えた：東門は車止めのジグザグと車、西の庭は防爆壁、坂の上はケーブルドラム。塀の外は方角ごとに、東は道の廃車、南はケーブルドラム、西は防爆壁、北は岩と瓦礫（`CONTROL_APPROACH`）
