# マルチプレイ体験の一本化

方針: [design-direction.md](design-direction.md)（拠点が主役・非同期の攻守・線に溶かす・新語を増やさない）。  
用語の正本: [glossary.md](glossary.md)／[`copy.ts`](../src/ringfall/view/copy.ts)。  
仕組みの詳細: [multiplayer.md](multiplayer.md)、[raid-loot.md](raid-loot.md)。  
体験の線: [ux-design.md](ux-design.md)。

体験の線（変えない）:

```
出撃 → 島で前線を押す → 持ち帰る → 拠点が育つ
```

マルチは別モードにしない。上の線のどこかに乗る。

---

## 決定（採用）

**案 A を採用する。** 信号所の「出撃」は **削除（A1）**。信号所は **送る** と **島の知らせの控え** だけ。

| 項目 | 決定 |
| --- | --- |
| 構造 | 案 A（守りは地図、攻めは前線、遠くは送るだけ） |
| 信号所の「出撃」 | **削除**。率いる写しはやらない |
| 知らせ | 遠征の知らせ／島の知らせを **一つの「島の知らせ」** に（リザルト優先、信号所は控え） |
| 工場パネルの遠征行 | **削除**（部隊の割は信号所だけ） |
| 島の番号入力 | 日常入口から外し、**折りたたみ**（友達用） |
| 仕返し | ボタンも語も **送る／取り返す** に揃える（新語にしない） |
| glossary リネーム | **同時に採用**（作業場・工場・レベルを上げる など） |
| **遠征に出す**（画面はまだ **送る**） | **日常の必須**（上級の任意ではない）。日次の合図・報酬・コストの形は [game-design-review.md](game-design-review.md) §5.2（提案・未実装）。改名は [glossary.md](glossary.md) pending（送る→遠征に出す） |
| 率いる遠征（raid-loot 段階 6） | **廃止（案 A と一致）**。遠い攻めは遠征に出すだけ。[raid-loot.md](raid-loot.md) 参照 |

一文のループ:  
野営で今日の守りか前線を見て出撃し、核で固めるか制圧して持ち帰り、倉庫と工場が育ち、信号所では遠くへ**遠征に出す**（日次の必須。画面コピーは承認まで送る）。

## 用語（画面の語）

| 語 | プレイヤーにとっての意味 |
| --- | --- |
| 野営地 | レイドのあいだ帰る庭。出撃の起点 |
| 地図の机 | 島の地図を見る場所。来る遠征もここ |
| 信号所 | 他の島との窓口（**送る**・島の知らせの控え） |
| 工場 | 自軍のロボットを育てる場所。遠征に出す部隊の元 |
| 作業場 | 隠れ家の設備を育てる場所（画面ラベルはこれだけ） |
| 中継ボックス | 島の拠点で、荷物を倉庫へ送る／切り上げて帰る箱 |
| 倉庫 | 拠点に置いた物の置き場 |
| 島の守り | 留守の防衛に回る在庫。送ると自動で積まれる |
| 来る遠征 | 他プレイヤー（や AI の島）が送りつけてくる部隊の予告 |
| 遠征 | 自分から他の島へ送る部隊 |
| 送る | 信号所から遠征を出す一手（非同期）。仕返しもこの語 |
| 出撃 | **車両／門から** レイドを始める一手（信号所には出さない） |
| 核 | 拠点の柱。制圧／固める |
| 制圧 | 敵や他プレイヤーの核を取って拠点を自分にする |
| 固める | 自分の核を守り、来る遠征や夜の襲撃をはねる |
| 取り返す | 他プレイヤーに取られた拠点を制圧して戻す |
| 前線 | 次に取れる敵／他プレイヤーの拠点の並び |
| 島の知らせ | 誰が何をしたかの短い記録（一つ） |
| 保護中 | 新しい島など、しばらく攻められない状態 |
| AI の島 | ゲームが動かすお隣。名前の横に AI と出る |
| お隣 | 海の向こうに並ぶ他の島（本物または AI） |
| レベルを上げる | 工場／作業場を 1 段階進める |

## 1. いまのマルチ体験（採用前の洗い出し・履歴）

正直に書く。機能はあるが、**一つの物語としてつながっていなかった**（採用前）。

### 1.1 触点一覧（採用前）

| # | いつ・どこ | 見える／やる | 断絶・重複 |
| --- | --- | --- | --- |
| A–G | 野営・地図・出撃・核・中継・リザルト | 守り／攻め／持ち帰り | 知らせが二重、固めるが初見で薄い |
| H–K | 信号所 | 送る／出撃／知らせ／仕返し | **攻めるが三分裂**（前線・送る・出撃） |
| L | 工場パネル | 遠征行 | 工場のプライマリが割れる |
| N–O | 保護中・AI | 入口が二枚 | 送る／出撃 |

### 1.2 削る・統合（採用）

| 候補 | 扱い |
| --- | --- |
| 信号所の「出撃」 | **削除（A1）** |
| 島の番号の手入力 | **折りたたみ**（日常はお隣カード） |
| 工場パネルの遠征一行 | **削除** |
| リザルトの遠征の知らせと島の知らせ | **一つの島の知らせ** |
| 仕返し | **送る／取り返す** の語に揃える |

## 2. 検討した案（履歴）

### 案 A（採用）— 「守りは地図、攻めは前線、遠くは送るだけ」

野営で今日の守りか前線を見て出撃し、核で固めるか制圧して持ち帰り、倉庫と工場が育ち、信号所では遠くへ送るだけする。

### 案 B（不採用・第二段階候補）— 攻める入口を前線に一本化

相手島も前線 UI に載せる。体験は太いが実装コスト大。案 A のあとに回す。

## 3. 採用後の一本の絵

```
野営
  ├ 地図の机 … 今日の来る遠征（守り）
  ├ 次の一手 … 固める／取り返す／前線／工場
  └ 車両 … 出撃
       ↓
レイド … 核で固める or 制圧
       ↓
中継ボックス … 倉庫へ送る（島の守りは自動）
       ↓
リザルト … 倉庫へ届いた ＋ 島の知らせ（一つ）
       ↓
拠点が育つ … 倉庫・工場・作業場
       └ 信号所 … お隣へ送る（遠くの非同期攻め）／島の知らせの控え
```

覚えること（最大）:

1. 出撃して前線の核を取る  
2. 荷物は中継ボックスで倉庫へ  
3. 来る遠征は地図で見て、核で固める  
4. 遠くは信号所から遠征に出す（毎日の一手。画面はまだ送る）
