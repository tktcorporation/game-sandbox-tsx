# マルチプレイ体験の一本化

方針: [design-direction.md](design-direction.md)（拠点が主役・非同期の攻守・線に溶かす・新語を増やさない）。  
用語の正本: [glossary.md](glossary.md)／[`copy.ts`](../src/ringfall/view/copy.ts)。  
仕組みの詳細: [multiplayer.md](multiplayer.md)、[raid-loot.md](raid-loot.md)。  
体験の線: [ux-design.md](ux-design.md)。  
対人の分かりやすさ（CoC 型）: [pvp-clarity.md](pvp-clarity.md)。

体験の線（変えない）:

```
出撃 → 島で前線を押す → 持ち帰る → 拠点が育つ
```

マルチは別モードにしない。上の線のどこかに乗る。

---

## 決定（採用）

**方向 A「お隣は自分の島の前線に立つ」を採用する（2026-11-25／TKT-195）。** それ以前の案 A（E4＋穴 A＋短いレイド）の上に、攻めと前線を一本化する。

信号所の「出撃」は **削除（A1）**。信号所の『遠征に出す』ボタンは **置かない**（送信処理も PR6 で削除）。信号所は **島の知らせ・お隣・トロフィー・チーム**（作り順④）。

**2026-11-23 追記（CoC 型）／2026-11-24 コード削除:** 守りは**自動**（来る遠征の予告→核で固めるの迎撃 UI は**削除済み**）。攻めだけ能動で、入口は **出撃一つ**。結果は **島の知らせ** で後から見る。[pvp-clarity.md](pvp-clarity.md)。復活は Git 履歴から（`FEATURES` なし）。

| 項目 | 決定 |
| --- | --- |
| 構造 | **方向 A**。守りは自動／攻めは門からの普段の出撃（自分の島の前線に立つお隣の拠点） |
| 取り合う拠点 | 外側の拠点すべて（海または地図境界。内側と野営・倉庫・作業場・工場は除く）。海路スロットは 4 面のまま |
| あと N | **島の解放を外す**方針によりゴールとしては使わない（[design-direction.md](design-direction.md)）。当面の帯表示の削除は後。取り合う拠点は部隊戦の力とトロフィーに効く |
| 守備隊 | 相手の拠点＝持ち主の工場の部隊＋島の守り |
| トロフィー | お隣の組み合わせに使う（近いトロフィーどうし） |
| その日の守り | 取られた拠点は、その日のうちは取られない。作り順③: 取られたあとは島全体が同日中守り／喪失上限 1 |
| 反応型守り（来る遠征→固める） | **コード削除**（2026-11-24）。サーバーの自動解決は残す |
| 信号所の「出撃」 | **削除**。率いる写しはやらない |
| 信号所の『遠征に出す』 | **削除**（ボタン済み／送信処理は PR6）。日次必須の合図も **廃止** |
| 短いレイド／○○の前線 | **削除**（TKT-195・PR6）。別舞台・別入口を無くす |
| 海の道／地図の四隅のお隣の島 | **削除**（TKT-204・案 A）。攻め先は海岸拠点の旗。信号所の「お隣の島」カードは残す |
| 知らせ | **一つの「島の知らせ」**（守りの記録＝CoC 防衛ログ相当。リザルト優先、信号所は控え）。取られた行から **やり返す**（TKT-204・案 F） |
| 工場パネルの遠征行 | **削除** |
| 島の番号入力 | **折りたたみ**（友達用） |
| 次の一手の語 | **攻める**（拠点名付き。旧・取り返す／○○の前線と統合） |
| ランキング | **トロフィー**（組み合わせにも使用） |
| 率いる遠征（raid-loot 段階 6） | **廃止**（写し全体・信号所出撃は戻さない） |
| 遠征の拠点の収入 | **拠点の収入に一本化**（PR5） |

一文のループ:  
野営で前線を見て**出撃**し、自分の島の前線に立つお隣の拠点を**攻める**（核 · 制圧）して持ち帰る。守りは工場と島の守りが勝手に行い、結果は島の知らせで見る。倉庫と工場が育ち、トロフィーが動き、お隣の相手が決まる。

## 用語（画面の語）

| 語 | プレイヤーにとっての意味 |
| --- | --- |
| 野営地 | レイドのあいだ帰る庭。出撃の起点 |
| 地図の机 | （**削除済み** PR4）島の地図・トロフィーを見ていた設備。出撃地図は門、トロフィー等は信号所 |
| 信号所 | 他の島との窓口（島の知らせ・お隣・トロフィー・チーム・島の守り）。攻めの入口ではない |
| 工場 | 自軍のロボットを育てる場所（留守の自動防衛にも効く） |
| 作業場 | 隠れ家の設備を育てる場所（画面ラベルはこれだけ） |
| 中継ボックス | 島の拠点で、荷物を倉庫へ送る／切り上げて帰る箱 |
| 倉庫 | 拠点に置いた物の置き場 |
| 島の守り | 留守の防衛に回る在庫。倉庫へ送ると自動で積まれる |
| 来る遠征 | （予告 UI は削除済み）他プレイヤーが送りつけてくる部隊。自動解決され、結果は島の知らせ |
| 遠征 | 他プレイヤーとの拠点の奪い合い（お隣が前線に立つ拠点） |
| 攻める | 自分の島の前線に立つお隣の拠点へ出撃し核を制圧する |
| ○○の前線 | （削除予定）短いレイドの入口だった印 |
| トロフィー | 取ると増え取られると減る。お隣の組み合わせにも使う |
| 出撃 | **門から** レイド／攻めを始める一手（対人攻めの唯一の入口） |
| 核 | 拠点の柱。制圧／固める（来る遠征の閉門） |
| 制圧 | 敵や他プレイヤーの核を取って拠点を自分にする |
| 固める | 来る遠征をはねる閉門。予告 UI・迎撃導線は削除済み。夜の襲撃は PR3 で削除済み |
| 前線 | 次に取れる敵／他プレイヤーの拠点の並び |
| 島の知らせ | 誰が何をしたかの短い記録（守りの結果＝防衛ログ相当） |
| 保護中 | 新しい島など、しばらく攻められない状態 |
| 守り中 | 外側を取られたあとの島全体の盾（作り順③）。残り時間付き |
| チーム | 4 人の組（作り順④）。空きは AIの仲間。外側の拠点数を表示 |
| 今日取られた | 外側拠点の喪失上限の表示（n/1） |
| AI の島 | ゲームが動かすお隣。名前の横に AI と出る |
| お隣 | 海の向こうに並ぶ他の島（本物または AI） |
| レベルを上げる | 工場／作業場を 1 段階進める |

## 2. 検討した案（履歴）

### 案 A（履歴・2026-11-23）— 「守りは地図、攻めは前線」＋ E4

野営で前線を見て出撃し、**攻める**（他プレイヤー陣地／お隣の前線の短いレイド）して持ち帰る、という薄い実装。方向 A がこれを置き換える。

### 案 B（履歴）— 相手島も前線 UI に載せる

体験は太いが実装コスト大、と当時は後回し。方向 A が「相手の拠点が自分の島の前線に立つ」形で同じ線を満たす。

### 方向 A（採用・2026-11-25）— 「お隣は自分の島の前線に立つ」

外側の拠点をお隣と取り合う（作り順②）。門からの普段のレイドで核を制圧＝攻めた。短いレイドと「○○の前線」は消す。[design-direction.md](design-direction.md)。

## 3. 採用後の一本の絵

```
野営
  ├ 次の一手 … 攻める（拠点名）／前線／工場
  ├ 門 … 出撃（島の眺め。お隣の拠点も普通の拠点）
  └ 信号所 … 島の知らせ・お隣・トロフィー・チーム・島の守り（遠征ボタンなし）
       ↓
レイド … 前線の核 · 制圧（敵の拠点／お隣の拠点）
       ↓
中継ボックス … 倉庫へ送る（島の守りは自動）
       ↓
リザルト … 拠点の持ち分 → 島の知らせ → トロフィー → 倉庫へ届いた（旧「あと N」は島の解放ゴールとしては使わない）
       ↓
拠点が育つ … 倉庫・工場・作業場（育てた分が他人から見た守りになる）
```

覚えること（最大）:

1. 出撃して前線の核を取る（お隣の拠点も同じ）  
2. 荷物は中継ボックスで倉庫へ  
3. 攻められた結果は島の知らせで見る（守りは自動）
