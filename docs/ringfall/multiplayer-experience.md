# マルチプレイ体験の一本化

方針: [design-direction.md](design-direction.md)（拠点が主役・非同期の攻守・線に溶かす・新語を増やさない）。  
用語の正本: [glossary.md](glossary.md)／[`copy.ts`](../src/ringfall/view/copy.ts)。  
仕組みの詳細: [multiplayer.md](multiplayer.md)、[raid-loot.md](raid-loot.md)。  
体験の線: [ux-design.md](ux-design.md)。  
対人の分かりやすさ（CoC 型）: [pvp-clarity.md](pvp-clarity.md)。

体験の線（変えない）:

```
出撃 → 島で前線を押す → 持ち帰る → 拠点が育つ
```

マルチは別モードにしない。上の線のどこかに乗る。

---

## 決定（採用）

**案 A を採用する。** 信号所の「出撃」は **削除（A1）**。遠い攻めは **E4（地図上の陣地／お隣の前線を出撃で制圧）**。信号所の『遠征に出す』ボタンは **置かない**。信号所は **島の知らせ・お隣・トロフィー**。

**2026-11-23 追記（CoC 型）／2026-11-24 コード削除:** 守りは**自動**（来る遠征の予告→核で固めるの迎撃 UI は**削除済み**）。攻めだけ能動で、入口は **出撃一つ**。結果は **島の知らせ** で後から見る。[pvp-clarity.md](pvp-clarity.md)。復活は Git 履歴から（`FEATURES` なし）。

| 項目 | 決定 |
| --- | --- |
| 構造 | 案 A＋E4。守りは自動／攻めは出撃（地図上の他プレイヤー陣地／○○の前線） |
| 反応型守り（来る遠征→固める） | **コード削除**（2026-11-24）。サーバーの自動解決は残す |
| 信号所の「出撃」 | **削除**。率いる写しはやらない |
| 信号所の『遠征に出す』 | **削除**（E4）。日次必須の合図も **廃止** |
| 知らせ | **一つの「島の知らせ」**（守りの記録＝CoC 防衛ログ相当。リザルト優先、信号所は控え） |
| 工場パネルの遠征行 | **削除** |
| 島の番号入力 | **折りたたみ**（友達用） |
| 次の一手の語 | **攻める**（旧・取り返すと統合） |
| 穴（攻め先なし） | **穴 A** — お隣の「○○の前線」印（出撃で選ぶ） |
| ランキング | **トロフィー T1** |
| 率いる遠征（raid-loot 段階 6） | **廃止**（写し全体・信号所出撃は戻さない） |
| 他の人の島へ出撃して攻める | **X2** — 短いレイド。攻め側の予告待ちなし。実島はサーバーが結果確定 |

一文のループ:  
野営で前線／攻め先を見て**出撃**し、**攻める**（自分の島の陣地＝E4、お隣島の一部＝X2）して持ち帰る。守りは工場と島の守りが勝手に行い、結果は島の知らせで見る。倉庫と工場が育ち、トロフィーが動く。

## 用語（画面の語）

| 語 | プレイヤーにとっての意味 |
| --- | --- |
| 野営地 | レイドのあいだ帰る庭。出撃の起点 |
| 地図の机 | 島の地図を見る場所（トロフィー・前線）。来る遠征の予告は出さない（反応型守り削除済み） |
| 信号所 | 他の島との窓口（島の知らせ・お隣・トロフィー）。攻めの入口ではない |
| 工場 | 自軍のロボットを育てる場所（留守の自動防衛にも効く） |
| 作業場 | 隠れ家の設備を育てる場所（画面ラベルはこれだけ） |
| 中継ボックス | 島の拠点で、荷物を倉庫へ送る／切り上げて帰る箱 |
| 倉庫 | 拠点に置いた物の置き場 |
| 島の守り | 留守の防衛に回る在庫。倉庫へ送ると自動で積まれる |
| 来る遠征 | （予告 UI は削除済み）他プレイヤーが送りつけてくる部隊。自動解決され、結果は島の知らせ |
| 遠征 | 他プレイヤーとの拠点の奪い合い（E4） |
| 攻める | 出撃で他プレイヤー陣地（E4）／○○の前線の短いレイド（X2）へ行き核を制圧する |
| ○○の前線 | 穴 A：航路開のお隣に出す攻められる印。出撃で選ぶと短いレイドへ |
| トロフィー | T1：取ると増え取られると減る |
| 出撃 | **車両／門から** レイド／攻めを始める一手（対人攻めの唯一の入口） |
| 核 | 拠点の柱。制圧／（夜の）固める |
| 制圧 | 敵や他プレイヤーの核を取って拠点を自分にする |
| 固める | 夜の襲撃向けなど。来る遠征の迎撃導線は削除済み |
| 前線 | 次に取れる敵／他プレイヤーの拠点の並び |
| 島の知らせ | 誰が何をしたかの短い記録（守りの結果＝防衛ログ相当） |
| 保護中 | 新しい島など、しばらく攻められない状態 |
| AI の島 | ゲームが動かすお隣。名前の横に AI と出る |
| お隣 | 海の向こうに並ぶ他の島（本物または AI） |
| レベルを上げる | 工場／作業場を 1 段階進める |

## 2. 検討した案（履歴）

### 案 A（採用）— 「守りは地図、攻めは前線」＋ E4

野営で今日の守りか前線を見て出撃し、核で固めるか**攻める**（他プレイヤー陣地／お隣の前線）して持ち帰り、倉庫と工場が育ち、トロフィーが動く。信号所に遠征ボタンは置かない。

### 案 B（履歴）— 相手島も前線 UI に載せる

体験は太いが実装コスト大、と当時は後回し。**E4＋穴 A** が同じ線を薄い実装で満たす。

## 3. 採用後の一本の絵

```
野営
  ├ 地図の机 … 今日の来る遠征（守り）／トロフィー
  ├ 次の一手 … 固める／攻める／前線／工場
  └ 車両 … 出撃
       ↓
レイド … 核で固める or 攻める（制圧）
       ↓
中継ボックス … 倉庫へ送る（島の守りは自動）
       ↓
リザルト … 倉庫へ届いた ＋ 島の知らせ（一つ）
       ↓
拠点が育つ … 倉庫・工場・作業場
       └ 信号所 … 島の知らせ・お隣・トロフィー（遠征ボタンなし）
```

覚えること（最大）:

1. 出撃して前線／他プレイヤー陣地の核を取る（攻める）  
2. 荷物は中継ボックスで倉庫へ  
3. 来る遠征は地図で見て、核で固める  
4. 攻め先が無いときはお隣の「○○の前線」へ（穴 A）
