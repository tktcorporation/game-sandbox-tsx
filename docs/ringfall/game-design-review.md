## 2. 問題（影響の大きい順）

### P1 — 初回セッションが「前線を押す」を教えない

**何が起きるか:** 最初の約 10 分は撃ち合い・箱・静かめの脱出・依頼（グラント撃破／廃村脱出／医務室）に寄る。核の制圧・固める・来る遠征・取り返すは、触らなくてもレイドが終わる。  
**なぜ痛いか:** 線の真ん中（前線）が「任意の上級」に見え、拠点が育つ＝箱の売り買いだけに読まれる。design-direction「全部わからなくてよいが次の一手は明確」に対し、次の一手が前線ではないことが多い。  
**証拠:** 導入依頼は PvE／作業場寄り（`meta/quests.ts`）。地域表のボットは初期武器で核を補給所以外ほぼ制圧しない。キャンペーンでも序盤は拠点数が少ない日が続く。

### P2 — 長期ゴールが二つ並び、どれが「今月の勝ち」か曖昧 → **方針で解消（表示は未）**

**何が起きるか:** 作業場と島の解放がどちらも中〜長期に見えうる。  
**回答後:** 月次の勝ちは **島の解放**。作業場／工場は手段（design-direction「いまの主ゴール」）。残るのは野営／リザルトで一文に出すこと（提案 F）。  
**証拠:** balance.md 解放 約 21–23 日。

### P3 — 案 A の「遠くは遠征に出す」動機が薄い／ドキュメントが食い違う → **E4＋日次必須廃止で解消（実装は後続）**

**何が起きるか:** 遠征に出すの体感が弱い。段階 6（率いる）文書が案 A と食い違っていた。  
**回答後:** 日次必須は**廃止**。攻めは **E4（地図で攻める）**。raid-loot 段階 6 は廃止済み。画面語は 送る→遠征に出す→ボタン削除／攻める。  
**証拠:** キャンペーン `ai islands`：来た日 7–8／30 日。

### P4 — ダム湖の初〜中級の生還が目標を下回り、最初の「欲張り」が罰に感じやすい

**何が起きるか:** ダム湖 30 周で初心者 60%・普通 50% 生還（目標 70%+／55–75%）。人想定は 15–22 分滞在で増援 3–5 回。欲張り曲線は意図どおりだが、教えられていない前線を押さず箱を漁ると全滅しやすい。  
**なぜ痛いか:** オンボーディング（P1）と重なる。最初の失敗が「上手く戦え」になり、「前線を一つ取って帰る」にならない。  
**証拠:** balance.md ダム湖表と「目標から外れている値」。

### P5 — 地域ごとの「1 レイドのリズム」がばらつきすぎる

**何が起きるか:** 港湾はボット中央値 ~2 分で船出し、掃討 0。発射場は生還 17–47%、入口から交戦まで速い。機械都市は時間長め・持ち帰り揺れ大。  
**なぜ痛いか:** 「出撃一回＝同じ濃さの物語」が地域で崩れる。セッション長の期待値が立たない。  
**証拠:** balance.md 地域表（harbor / launch / city）。

### P6 — 静かな間が長く、緊張の山谷が途切れる（ダム湖）

**何が起きるか:** どのロボットとも戦っていない最長が目標 45 秒以下に対し、約 49–64 秒。入口→拠点、制圧後→廃村の歩き。  
**なぜ痛いか:** コア戦闘の楽しさ（物陰・回り込み）が「移動の空白」で薄まる。  
**証拠:** balance.md meet 列。

### P7 — 「固める」の結果が初見で読みにくい

**何が起きるか:** 来る遠征／夜の襲撃をはねる行為だが、プロンプトが「核 · 固める」だけだと「何が起きる？」が残る（glossary でも要検討と既出）。  
**なぜ痛いか:** 案 A の守り入口（地図→固める）の理解コストが上がる。  
**証拠:** glossary 文言提案、ux-design Round のトースト補強はあるが初見の一語としては重い。

### P8 — 経済の「見える育ち」がクレジットと段に偏り、拠点収入が薄い

**何が起きるか:** 拠点を持つと日々クレジットが入るが、リザルトの主役は倉庫へ届いた物と工場／作業場。地図の色は動くが「拠点が現金を生んだ」が弱い。  
**なぜ痛いか:** 前線を押す理由が「色」と解放に寄り、CoC 的な「村が稼ぐ」感が弱い。  
**証拠:** `FRONT.income` は存在するが、プレイヤー向けの一文フィードバックが薄い（設計上のギャップ）。

## 4. 最初に作るべき 2–3（推奨順）

1. **A — 初回で前線の核を体験させる**  
   線の定義そのものをプレイヤーに渡す。UI ではなく「何をするとゲームが進むか」の設計。sim でダム湖の生還・掃討がどう動くかを見る。

2. **B + I — 案 A の物語を文書とフィードバックで閉じる**

3. **C または G — 初回の罰を学習可能にする／固めるを読めるようにする**  
   P4 が深刻なら C（数値）。守り入口の理解が先なら G（文言）。 ideally G を A と同時に。

### 5.3 『遠征に出す』いま何が起きるか（コード準拠・プレイヤー視点）

証拠: `view/expeditions.ts`、`island-net.ts` `sendExpedition`、`meta/expeditions.ts`、`worker` の島 API、[multiplayer.md](multiplayer.md)。

プレイヤーが信号所でお隣（または番号）の拠点を選んで **遠征に出す** を押すと:

1. **工場の部隊が 1 隊、自分の島の陣取りからいなくなる**（次の出撃でも守りが 1 隊薄い）。押した瞬間から割く。
2. **相手の島へ「その拠点を狙う部隊」が登録される**（サーバー、または AI の島ならブラウザ内）。相手側では **来る遠征**／島の知らせに「誰かが拠点へ遠征に出した」と出る。
3. **立つまでの時間は相手の種類で違う。** 本物の島（サーバー）は受け付けから約 **12 時間**（`EXPEDITION.notice`）後に拠点へ立つ。**AI の島**はブラウザ内時計で、向かう **20 分**→攻める **40 分**のあと、取れるか全滅かが決まる（`AI.coming` / `AI.fighting`）。どちらの場合も、立つ前に核を**固める**と入れない。相手が自分で出撃していれば、レイド中にその部隊と戦うこともある。
4. 部隊が拠点を取れれば、**相手の島のその拠点は自分のもの**になる（紫／緑の印）。取れなければ全滅などで戻る。
5. 保持中は、精算のたびに **遠征の拠点の収入**（自分の拠点収入と同じ単価）がクレジットで入る。
6. 信号所から**引き上げる**と部隊は工場に戻り、保持していた拠点は相手の島で敵に戻る。
7. 自分の島が攻められた知らせには **遠征に出す**（旧・仕返し）が付き、押すと同じ手順で相手の島を開ける。**取り返す**は、自分の島で他プレイヤー保持の核を制圧して戻す一手（別語）。

要するに: **出撃（自分の島を歩く）とは別ボタンで、工場のロボットを非同期に他島へ送り、拠点を奪う／奪われる仕組み**。いまの画面だけでは「押すと何が起こるか」が短い言葉で伝わっていない、というのが今回の指摘。

### 5.4 E4 — 地図上の他プレイヤー陣地を出撃で攻める — **採用済み**

前提: 率いる遠征（相手島の写しでレイド）は**廃止のまま**。自分の島を歩く。出発で相手を選ばない。

#### E1〜E3 — 不採用（記録）

| 案 | 要約 | 不採用の理由（要約） |
| --- | --- | --- |
| E1 生還ボーナス遠征 | 生還時に自動でお隣へ 1 隊 | 送り先が薄い |
| E2 核 1＝向こうへ 1 隊 | 制圧のたび相手島へ自動遠征 | 二重になりやすい |
| E3 出発でお隣を選ぶ | 出発時に相手を目標にする | 出発時に選ばない |

#### 確定した形

| 項目 | 決定 |
| --- | --- |
| **主経路** | **E4** — 地図上の他プレイヤー陣地（＋穴 A の前線）を出撃で制圧＝その人への攻め |
| **信号所『遠征に出す』ボタン** | **消す**。信号所は島の知らせ・お隣の看板・トロフィー |
| **穴（攻め先が無いとき）** | **穴 A** — 航路の開いたお隣に「○○の前線」印を地図に出す |
| **次の一手の語** | **攻める**（旧・取り返すと統合） |
| **旧日次必須**（§5.2） | **廃止** |

##### 地図上での見せ方

| もの | 見せ方 |
| --- | --- |
| 他プレイヤー保持の拠点（`rival:`） | 別色＋**持ち主の名前**（AI なら名前＋「AI」） |
| 穴 A「○○の前線」 | 航路開・そのお隣の陣地がまだ無いとき、海岸側ノードに攻められる印 |
| 海の向こうのお隣の島 | 島の影に持ち主の名前（近づけない） |

##### 攻めた結果

1. 核を制圧（既存の取り返すと同じ戦闘）。
2. 拠点は自分のもの。相手の遠征保持なら終わり、相手の島の知らせに取られた系。
3. **トロフィー T1** が増える（§5.5）。取られた側は減る。
4. 来る遠征は対称（相手も同じ E4）。ボタン遠征の 12 時間予告は手動送り廃止に伴い、AI／既存の来る遠征経路に限定。

##### 取り返すとの関係 — **統合（確定）**

動作は同じ。画面語は **攻める**。旧語「取り返す」はプレイヤー向けに出さない（`BANNED`）。

**やらない:** 率いる遠征、出発で相手選択、信号所からの手動遠征ボタン。

### 5.5 トロフィー型ランキング — **T1 採用済み**

| 項目 | 内容 |
| --- | --- |
| **増える** | 地図上で他プレイヤー（や AI）の陣地／前線を出撃で制圧した |

| 旧日次必須 | **廃止** |

### 5.8 他の人の島へ攻めに行く — **X2 採用・実装済み**

ユーザー追記:「他の人の島にも攻めに行ける感じがいい」。E4（自分の地図上の陣地を制圧）は確定のまま。ここに足すのは **相手の島そのものへ出撃して攻める** 層。

**採用: X2 — 相手島の一部だけの短いレイド。** おすすめ案としてユーザーが決定（2026-11-23）。予告は **来る遠征と同じ**（`EXPEDITION.notice`）。X1（写し全体）・X3（CoC 型防衛配置）は採らない。AI 島はブラウザ内、**実プレイヤーの島**は Island DO の `x2` 遠征＋`POST …/assault` で結果確定。

当時の **率いる遠征（raid-loot 段階 6）** は案 A で廃止済み（[raid-loot.md](raid-loot.md)、[multiplayer-experience.md](multiplayer-experience.md)）: 信号所に「出撃」を並べて入口が分裂する・相手島の写し**全体**でレイドする・覚える操作が増える、が理由。X2 はその理由を次のように避ける。

**維持（変えない）:** 信号所ボタン削除、穴 A、語は **攻める**、トロフィー T1。

#### 意味（プレイヤーから見た一手）

1. 地図の **「○○の前線」**（穴 A）または攻める印から、車両／門で出撃する（信号所にボタンを戻さない）。
2. 出撃を決めた時点で相手島には **来る遠征** と同じ予告が立つ（固めると入れない）。予告が終わるまで相手は守れる。相手がオンラインでなくても成立。
3. プレイヤー側のレイドは **相手島の公開ノード数個だけ** を舞台にした短い出撃（写しワールド全体は歩かない）。目標の核を **制圧** して帰る。
4. 制圧成功で **T1 トロフィー**（E4 と同じ `trophyDelta`／`trophySwap`。攻める側は settle、守る側は同期の `applySync`。二重計上なし）。拠点の移動はサーバーが確定し、両者に同期。相手には「奪取」の知らせ。

| こうする | こうしない |
| --- | --- |
| 入口は地図の穴 A／攻めるだけ | 信号所に「出撃」「遠い攻め」ボタンを戻す |
| 戦場はターゲット周辺の数ノード | 相手島の写し全体を歩く段階 6 |
| 予告は来る遠征と同じ時間・語彙 | 即時奇襲や別モードの盾 UI |
| トロフィーは E4 と同じ式・一度だけ | X2 専用の星や別カウント |

#### 却下した案（記録）

| 案 | 却下理由 |
| --- | --- |
| X1 穴 A から写し全体へ出撃 | 段階 6 に近い。戦場が広く sim／体験が重い |
| X3 非同期防衛配置（CoC 型） | 新規 UI・配置ハッシュが大きく、既存レイド線から外れる |

#### 実装メモ

- `meta/incursion.ts`（部分集合）＋`meta/assault.ts`（予告）＋地図の穴 A。ゲートの通常レイド表は変えない（X2 は別シナリオ）。
- 実島: `POST …/expeditions` に `x2: true` → 予告満了後に短いレイド → `POST …/assault` `{ id, won }`。数の戦いには乗せず、固めると 409 `fortified`。詳細は [multiplayer.md](multiplayer.md)。
- スタック: docs → E4／T1（#192〜#194）→ AI X2（#195〜#197）→ 実島 X2（本変更）。
