# RINGFALL 用語集（プレイヤー向けコピーの SoT）

コードの正本: [`src/ringfall/view/copy.ts`](../src/ringfall/view/copy.ts)（`TERM` / `PHRASE`）。  
検査: `npm run lint:ringfall-copy`（禁止語・定義語の生リテラル）。

設計方針: [design-direction.md](design-direction.md)（覚えさせる名前を増やさない、1 概念 1 語）。  
マルチ一本化: [multiplayer-experience.md](multiplayer-experience.md)（案 A 採用）。  
場所表: [ux-design.md](ux-design.md)。

**ルール:** 同じものを別名で呼ばない。新しい画面文言は `copy.ts` に足してから出す。プレイヤーに内部名（depot / pad / parcel）を見せない。

## 用語表

| 用語（画面） | プレイヤーにとっての意味 | 出る場所 |
| --- | --- | --- |
| 野営地 | レイドのあいだ帰る拠点の庭 | リザルト「野営地に戻る」、生還 |
| 地図の机 | 島の地図を見る・来る遠征を確認する場所 | 野営ラベル、次の一手、パネル |
| 依頼板 | 依頼と記録を選ぶ・納品する | 野営、次の一手 |
| 倉庫の棚 | 持ち帰った物を置く・持ち出す | 野営ラベル、パネル |
| 商人の屋台 | 物を買う・売る | 野営ラベル、パネル |
| 作業場 | 隠れ家の設備（医務室など）を育てる場所 | 野営ラベル、パネル頭・側 |
| 工場 | 自軍のロボットを育てる場所 | 野営ラベル、パネル頭・側、次の一手 |
| 信号所 | 島の知らせ・お隣・トロフィーの窓口（遠征ボタンは置かない） | 野営ラベル、パネル |
| 車両 / 門 | 出撃の入口 | 次の一手、出撃 |
| 中継ボックス | 島の拠点で倉庫へ送る／切り上げる箱 | プロンプト、トースト、リザルト |
| 倉庫 | 拠点に置ける物の置き場（棚・容量） | リザルト「倉庫へ届いた」など |
| 島の守り | 留守の防衛に回る在庫（自動） | トースト、リザルト、信号所 |
| 来る遠征 | 他プレイヤーが送りつけてくる部隊 | 地図の机、次の一手、固める |
| 遠征 | 他プレイヤーとの拠点の奪い合い（E4）。来る遠征の対 | 地図、知らせ |
| 攻める | 地図上の他プレイヤー陣地（E4）／お隣島の一部への短いレイド（X2）で核を制圧する（旧・取り返す） | 次の一手、地図 |
| ○○の前線 | 航路の開いたお隣で、まだ陣地が無いときに地図に出す攻められる印（穴 A）。X2 の入口 | 地図 |
| トロフィー | T1：他プレイヤーの拠点を取ると増え、取られると減る（`TERM.trophy`） | 信号所／地図の机／リザルト |
| 核 | 拠点の柱。制圧／固める | プロンプト、トースト |
| 前線 | 次に取れる敵／他プレイヤーの拠点の並び。お隣の「○○の前線」印も含む | 次の一手、出撃、地図 |
| 出撃 | 車両／門からレイドを始める | 出撃する、次の一手（信号所には出さない） |
| レベルを上げる | 工場／作業場を 1 段階進める | 次の一手、リザルト |
| 固める | 自分の核を守り、夜／来る遠征をはねる | 核プロンプト、トースト |
| 制圧 | 敵／他プレイヤーの核を取って拠点を自分に | 核プロンプト、トースト |
| 倉庫へ送る | バッグの物を拠点の倉庫へ（**攻めるとは別**） | 中継ボックス |
| 切り上げて生還 | バッグ空でレイドを終える | 中継ボックス |
| 倉庫へ届いた | 生還後、倉庫に入った物 | リザルト |
| 隠れ家 | 医務室・作業台などの設備一式（**場所名ではない**） | バッグ注釈など |
| 島の知らせ | 他島・遠征の出来事の短文（一つ） | リザルト、信号所の控え |
| 夜の襲撃 | 日をまたいで敵が拠点を取る攻撃 | トースト |

## 文言（【元 / 案 / 理由】）— 採用済み

| 元 | 案 | 理由 |
| --- | --- | --- |
| 次：工房 · 次の段を上げる | 次：作業場 · レベルを上げる | ラベルと一致。工房は画面に無い |
| 次の段を上げる | レベルを上げる | 「段」は初見で何段目か不明。レベルは通じる。`copy.ts` の `TERM.raiseLevel` 一箇所 |
| 次：工場 · 次の段を上げる | 次：工場 · レベルを上げる | 同上 |
| （側）隠れ家 | 作業場 | 同じ場所の別名をやめる。隠れ家は設備の総称に残す |
| （側）自軍のロボット | 工場 | 場所名を 1 つに |
| 次の段を上げられる | レベルを上げられる | リザルトの「できる」 |
| 遠征の知らせ | 島の知らせ | 帰営の物語を一本に |
| 仕返し | 遠征に出す | 当時の信号所ボタンに揃えた（のち E4 でボタン廃止） |
| 送る | **遠征に出す** | 当時の画面語。E4 採用後はボタン廃止 |
| {拠点}へ送った | {拠点}へ遠征に出した | 結果トースト（レガシー経路） |
| {誰}が{拠点}へ遠征隊を送った | {誰}が{拠点}へ遠征に出した | 島の知らせ |
| 取り返す | **攻める** | E4。地図上の他プレイヤー陣地を出撃で制圧する一手に語を寄せる |
| 遠征に出す（ボタン） | （削除） | 攻めはすべて地図の制圧。信号所は知らせ・お隣・トロフィー |
| （なし・他島写し全体） | **X2：お隣の一部だけ短いレイド**（`TERM.shortRaid`） | 段階 6 を避けつつ「他の島へ攻めに行く」感。予告は来る遠征と同じ |

### 「段を上げる」の検討（判断記録）

| 案 | 長所 | 短所 |
| --- | --- | --- |
| 段を上げる（「次の」だけ削る） | 既存に近い | 「段」が初見で不明のまま |
| **レベルを上げる（採用）** | 初見で通じる。SoT 一箇所 | 英語由来 |
| 育てる | 「拠点が育つ」と韻 | +1 段階か曖昧 |

異論があれば `TERM.raiseLevel` を一行戻すだけでよい。

### 「送る」→「遠征に出す」→ボタン廃止（判断記録）

| 段階 | 扱い |
| --- | --- |
| 送る → 遠征に出す | 来る遠征と対。画面語として採用済み（スタック） |
| E4 採用後 | 信号所ボタンは**置かない**。攻めは地図の **攻める** |
| 取り返す → 攻める | 同じ動作。語を寄せる |

### 「攻める」の検討

| 案 | 長所 | 短所 |
| --- | --- | --- |
| **攻める（採用）** | 出撃・前線と同じ線。取り返すと一本 | 「守る」と対で通じやすい |
| 取り返すのまま | 既存 | 「自分の拠点を戻す」に聞こえ、攻め先ゼロで詰む |

## 開発者向け

- 新しいプレイヤー向け文字列 → `TERM` / `PHRASE` に追加 → UI から参照 → この表に 1 行
- `BANNED` に足した語は UI ソースに生で書けない
- 採用した同義語は `PENDING_SYNONYMS` から `BANNED` へ移す
- 「送る」は exact match のみ禁止（`倉庫へ送る` ⊂ 含まない）— `scripts/ringfall-copy-lint.ts`
