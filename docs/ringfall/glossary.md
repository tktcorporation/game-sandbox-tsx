# RINGFALL の言葉（ドメイン用語の正本）

**一語一義。** この表の語は、画面・設計資料・PR・会話・エージェントの作業のどこで使っても、ここに書いた一つの意味だけを指す。意味が二つに割れそうになったら、語を増やす前にここで決める。

- 画面に出す文字列の正本は [`src/ringfall/view/copy.ts`](../../src/ringfall/view/copy.ts)（`TERM` / `PHRASE`）。検査は `npm run lint:ringfall-copy`
- 体験の筋は [holdings-raid.md](holdings-raid.md)（島で漁り、別プレイヤーの陣地を攻める）と下の「決めたこと」。判断基準は [design-direction.md](design-direction.md)
- 過去の言い換えの記録は [glossary-history.md](glossary-history.md)（定義としては読まない）

書き方: **語** — 定義（一文）。*混同しない:* 似た語との違い。`コード名`。

---

## 0. 体験の筋（一文）

自分の**島**で**漁り**、**拠点**を**制圧**して**陣地**を広げる。**別プレイヤー**の陣地へ**攻め**に行き、**トロフィー**と**島の守り**を持ち帰る。留守のあいだ自分の陣地は**守り**が勝手に戦う。陣地を取りうるのは別プレイヤー（AI を含む）だけ。**日**は現実の暦の日で、ゲームの中では進まない。

---

## 1. 時間

| 語 | 定義 | 混同しない | コード |
| --- | --- | --- | --- |
| **日** | 現実の暦の一日（日本時間の 0 時で替わる）。デイリーの報酬・盾・一日の上限はこれで数える | **レイドの回数ではない。** 出撃しても、攻めても、日は進まない | `calendarDay()` / `islandDay()`（`meta/days.ts`）。島の盾だけはまだ UTC（`utcDayEnd()`） |
| **今日** | いまの日 | 「今日の作戦」は今日の目安の一行で、日を進める仕組みではない | — |
| **持ち時間** | 一回の攻めの制限時間（5 分）。切れたら生還扱い | 陣取り戦の時間切れ（全滅扱い）とは別 | `SORTIE.time` |
| **島の日数** | 島が始まった暦の日から数えた日数。AI プレイヤーの育ちと攻め先の入れ替わりに使う。画面には出さない | 「n 日目」とは書かない | `Profile.since`、`islandDay()` |

## 2. 場所

| 語 | 定義 | 混同しない | コード |
| --- | --- | --- | --- |
| **世界** | 一つの島の地形全体（約 2460×1880 m） | 島と同じ広がりだが、世界は地形、島は持ち物 | `WORLD` |
| **島** | 一人のプレイヤーが持つ世界の一枚。自分の島と別プレイヤーの島がある | 海の向こうの別マップではない。どの島も同じ地形 | `IslandDO`、島のコード |
| **地域** | 島の四つの区分（ダム湖・港湾地帯・機械都市・発射場） | 拠点の集まり。入口と脱出地点は地域ごと | `REGIONS` |
| **拠点** | 地域の中の、名前と核を持つ場所（21 か所） | 持ち主が誰でも「拠点」。持ち主付きで言うときは陣地 | `NODES`、`POI_DEFS` |
| **陣地** | 誰かが制圧して持っている拠点。自分の陣地／別プレイヤーの陣地 | 拠点＝場所、陣地＝持ち物。野営地・倉庫・作業場・工場は陣地ではない（攻められない） | `poiState` が `own` |
| **小拠点** | 拠点の間の野に立つ、元は基地の設備だった場所。漁れて守備隊がいるが、核も持ち主もない | 拠点ではない（前線にも陣地にもならない） | `OUTPOSTS` |
| **野営地** | 自分の島の南の浜にある柵の中。設備があり、レイドの合間に歩く | 陣地ではない。攻められない | `CAMP` |
| **設備** | 野営地の中の場所: 倉庫の棚・商人の屋台・作業場・工場・信号所・門 | — | ステーション |
| **門** | 出撃の唯一の入口。出ると出撃地図が開く | — | `TERM.gate` |
| **信号所** | 別プレイヤー・トロフィー・島の知らせの窓口 | 出撃はここからしない | `TERM.signal` |
| **入口** | 地域の外れの、歩いて入る地点。知っている入口からだけ始められる | 中継ボックスから始めるのとは別 | `ENTRIES` |
| **中継ボックス** | 拠点の道の脇の箱。荷物を倉庫へ送る／空なら切り上げて生還。攻めはここから始まりここで終わる | — | `DEPOTS`（画面に depot と出さない） |
| **脱出地点** | 地域ごとの帰り道（迎えの船・機・待ち） | 中継ボックスとは別 | `EXTRACTS` |
| **前線** | 自分の陣地か野営地に隣り合う、ロボットの拠点の並び。核を制圧できるのはここだけ | **ロボットとの前線の意味だけ。** 別プレイヤーとの境目には使わない | `frontNodes()` |
| **核** | 拠点の中心の柱。ここを守り切ると制圧 | — | `TERM.core` |

## 3. 行い

| 語 | 定義 | 混同しない | コード |
| --- | --- | --- | --- |
| **出撃** | 門から出ること。行き先で漁りか攻めかが決まる | — | `TERM.sortie` |
| **レイド** | 一回の出撃から帰るまで。設計の語で、画面には出さない | — | `newRun()` |
| **漁り** | 自分の島へのレイド。ロボット相手に箱や小拠点を漁り、拠点を制圧し、生きて持ち帰る | 攻めとは行き先・敵・出方が違う（holdings-raid.md の表） | `Start` に `sortie` なし |
| **攻め／攻める** | 別プレイヤーの陣地へのレイド。その陣地の中継ボックスから始まり、核を制圧して星を取る | **自分の島の拠点を取るのは攻めではなく制圧。** 「取り返す」「取り合う」は使わない | `Start.sortie`、`TERM.attack` |
| **やり返す** | 自分の陣地を取った相手の陣地を攻め先にすること | 攻めの一つ。別の遊び方ではない | `TERM.revenge` |
| **偵察** | 攻める前に、相手の陣地の持ち主・トロフィー・守りを見ること | — | 門の攻める一覧 |
| **制圧** | 核を守り切って、その拠点を自分の物（漁り）または星（攻め）にすること | 掃討とは別 | `TERM.captureCore` |
| **掃討** | 拠点の守備隊を倒しきること。拠点は自分の物にならない | 制圧とは別 | — |
| **生還** | レイドを生きて終えること（脱出地点・中継ボックス・野営地へ帰る・攻めの持ち時間切れ） | — | `outcome: "extracted"` |
| **全滅** | レイド中に倒れて終わること。バッグの中身を失う | — | `outcome: "wiped"` |
| **倉庫へ送る** | 中継ボックスでバッグの物を倉庫へ送ること（全滅しても残る） | 「送る」単独は使わない | `TERM.sendToWarehouse` |
| **切り上げて生還** | バッグが空のとき中継ボックスでレイドを終えること | — | `TERM.cutAndExtract` |
| **レベルを上げる** | 作業場・工場で設備を一段進めること | 「段を上げる」は使わない | `TERM.raiseLevel` |

## 4. 人と陣営

| 語 | 定義 | 混同しない | コード |
| --- | --- | --- | --- |
| **別プレイヤー** | 自分以外の島の持ち主。本物の人と AI プレイヤーの両方を含む。攻め先になり、自分の陣地を取りうる唯一の相手 | 「お隣」とは呼ばない（隣り合っている必要はない） | `Neighbour`（コード名は後で揃える） |
| **AI プレイヤー** | ゲームが動かす別プレイヤー。本物の人が足りない分を埋める。表示は「{名前} · AI」 | 扱いは本物と同じ。本物と同じ名前を使わない | `meta/ai-islands.ts` |
| **ロボット** | 島にいる機械すべて | — | `Enemy` |
| **敵** | 島を持つ側のロボット（赤い目）。前線の拠点を守り、漁りのあいだ襲ってくる。**陣地は取らない** | 別プレイヤーは敵と呼ばない | `FACTION` |
| **野良機** | どこも持たない第三のロボット（黄色い目）。誰とも戦う | — | `Enemy.rogue` |
| **リオ** | レイドに付いてくる一人の相棒 | 自軍のロボットとは別。「仲間」「味方」と呼ばない | `ally.ts` |

| **守備隊** | 拠点に立つロボットの組。前線の拠点では敵の、別プレイヤーの陣地ではその人の | — | `garrison()` |

## 使わない語

意味が割れた語、または体験の筋から外れた仕組みの語。新しい文書・コード・画面に書かない。仕組みが残っているものは、コードごと消す作業の対象（holdings-raid.md 作り順⑦）。

| 語 | 使わない理由 | 代わり |
| --- | --- | --- |
| 取り合う／外側の拠点 | 別プレイヤーが自分の島の前線に立つ旧方式（作り順②）。攻めは相手の島へ行く | 攻める／陣地 |
| お隣 | 隣り合っている必要はない。相手は誰でも別プレイヤー | 別プレイヤー |
| 取り返す | 自分の拠点を戻すように聞こえる | 攻める（別プレイヤー）／制圧（自分の島） |
| n 日目・日が進む | 日をレイドの回数で数えていた | 日＝現実の暦の日 |
| チーム／AIの仲間／部隊戦／荒地の戦場／相手チーム／戦場の拠点／部隊戦の力／チームの得点／懸賞金 | 別マップの対抗戦（作り順④⑤⑥）。外側の拠点の数が力の種で、旧方式に依る。消す（決定 C） | 攻めの上に作り直すときに決める |
| 来る遠征／遠征に出す／固める | 削除済みの予告・送り出し・閉門の操作 | 守り（自動）、島の知らせ |
| 遠征 | 「相手が送る隊」と「自分が送る隊」の両方を指していた | 攻め（自分が行く）／守り（来られる） |
| 短いレイド／○○の前線／海の道 | 削除済み | 攻める |
| 依頼板／夜の襲撃／地図の机／車両／島の解放／決戦 | 削除済み | — |
| デポ／パーセル／pad（画面で） | 内部名 | 中継ボックス／島の守り／発着場 |
| 工房／段を上げる／送る（単独） | 言い換え済み | 作業場／レベルを上げる／倉庫へ送る |

## 決めたこと（大枠・2026-11-27）

一つ決めると残りが自然に決まる筋。細部はこれに沿って作業側で決める。

- **A. 拠点の収入は現実の時間で溜まる**（CoC の採掘機）。陣地ごとに溜まり、野営地で受け取る。攻められると溜まった分を持っていかれる → 攻める理由と守る理由が同じ数になる。レイドの回数で払う収入は消す
- **B. 陣地を取りうるのは別プレイヤーだけ**（本物も AI も同じ扱い）。島のロボットは陣地を取らない → 陣取り戦は「取られる心配」を持たない。ロボットに取られていた感触は AI プレイヤーの攻めが担う
- **C. チームと部隊戦は消す**。一人対一人の攻めの流れを先に固め、対抗戦はその上に作り直す
- **日は現実の暦の日**。出撃・攻めで日は進まない。日で数えるもの（盾・一日の上限・AI プレイヤーの育ち・攻め先の入れ替わり）は現実の日で数える

## 開発者向け

- 新しい画面の文字列 → `TERM` / `PHRASE` に足す → UI から参照 → この表に一行
- 語の意味を変えたら、旧い意味を [glossary-history.md](glossary-history.md) に【元／案／理由】で残す
- `BANNED`（`scripts/ringfall-copy-lint.ts`）に足した語は UI のソースに生で書けない。「送る」は完全一致だけ禁止
