# RINGFALL 用語集（プレイヤー向けコピーの SoT）

コードの正本: [`src/ringfall/view/copy.ts`](../src/ringfall/view/copy.ts)（`TERM` / `PHRASE`）。  
検査: `npm run lint:ringfall-copy`（禁止語・定義語の生リテラル）。

設計方針: [design-direction.md](design-direction.md)（覚えさせる名前を増やさない、1 概念 1 語）。  
マルチ一本化: [multiplayer-experience.md](multiplayer-experience.md)（案 A 採用）。  
場所表: [ux-design.md](ux-design.md)。

**ルール:** 同じものを別名で呼ばない。新しい画面文言は `copy.ts` に足してから出す。プレイヤーに内部名（depot / pad / parcel）を見せない。

## 文言（【元 / 案 / 理由】）— 採用済み

| 元 | 案 | 理由 |
| --- | --- | --- |
| 倉庫が満杯：売るか、作業場で倉庫を上げる | 倉庫が満杯：売るか、倉庫の棚で倉庫を上げる | 容量を上げる入口を倉庫の棚に寄せた（[warehouse.md](warehouse.md)） |
| （なし） | 次：倉庫の棚 · レベルを上げる | 倉庫が作れるとき棚へ |
| 倉庫 \| 3 \| 倉庫 +10 ずつ | 倉庫 \| 6 \| 倉庫 +10 ずつ（Lv6 で 100） | 後半も目標になるよう上限を伸ばした |
| 次：工房 · 次の段を上げる | 次：作業場 · レベルを上げる | ラベルと一致。工房は画面に無い |
| 次の段を上げる | レベルを上げる | 「段」は初見で何段目か不明。レベルは通じる。`copy.ts` の `TERM.raiseLevel` 一箇所 |
| 次：工場 · 次の段を上げる | 次：工場 · レベルを上げる | 同上 |
| （側）隠れ家 | 作業場 | 同じ場所の別名をやめる。隠れ家は設備の総称に残す |
| （側）自軍のロボット | 工場 | 場所名を 1 つに |
| 次の段を上げられる | レベルを上げられる | リザルトの「できる」 |
| 遠征の知らせ | 島の知らせ | 帰営の物語を一本に |
| 仕返し | 遠征に出す | 当時の信号所ボタンに揃えた（のち E4 でボタン廃止） |
| 送る | **遠征に出す** | 当時の画面語。E4 採用後はボタン廃止 |
| {拠点}へ送った | {拠点}へ遠征に出した | 結果トースト（レガシー経路） |
| {誰}が{拠点}へ遠征隊を送った | {誰}が{拠点}へ遠征に出した | 島の知らせ |
| 取り返す | **攻める** | E4。地図上の他プレイヤー陣地を出撃で制圧する一手に語を寄せる |
| 遠征に出す（ボタン） | （削除） | 攻めはすべて地図の制圧。信号所は知らせ・お隣・トロフィー |
| （なし・他島写し全体） | **X2：お隣の一部だけ短いレイド**（`TERM.shortRaid`） | 段階 6 を避けつつ「他の島へ攻めに行く」感。予告は来る遠征と同じ |
| 〜は固められていて攻められない | **〜へは今攻められない**（`assaultUnavailable`） | 固める削除後も短いレイド拒否が必要。固める語は使わない |
| 核を起動する（目標カード） | **核 · 制圧を始める**（`PHRASE.captureStart`） | プロンプトと同じ語。起動は画面語の正本に無い |
| {拠点}の解放（短いレイドの目標カード） | **{お隣}の{拠点}を攻める** | 解放は島だけ。出撃の目的「〜を攻める」と揃える |
| 前線：{拠点}を取る（目標カード） | **前線：{拠点}** | 次の一手・出撃の目的と同じ形 |
| 攻める拠点（今日の作戦の行名） | **目的**（`PLAN_GOAL`） | 出撃の側と同じ行名。攻めるは他プレイヤー相手だけ |
| {拠点}を取り返した · 倉庫へ届く | **{拠点}を制圧した · 倉庫へ届く**（`newsRetaken`） | 取り返すは禁止語。トースト「制圧した」と揃える |
| 遠征隊を全滅させた（島の知らせ） | **遠征隊を撃退した**（`newsWipedEnemy`） | 自分の隊の「攻めきれず」と語を分ける |
| 保持／全滅／奪還された（信号所・自分の遠征） | **取った／攻めきれず／失った**（`EXP_OUT_WORD`） | 「全滅」が双方向で曖昧だった |
| 次：門から短いレイド · …を攻める | **次：門から出撃 · …を攻める**（`nextShortRaid` → `nextAttack`） | 登録の有無で同じ一手の文が変わっていた |
| Lv{n} を建てる（工場）／Lv{n}（作業場・棚） | **Lv{n} · レベルを上げる** | 次の一手の動詞（`TERM.raiseLevel`）に揃える |
| 海の向こうの島（信号所の側見出し） | **お隣の島**（`TERM.seaIslands`） | 同じパネルのカード見出しと揃える |
| （なし・帯の数だけ） | **島の解放まで · 拠点 あと {n}**（`liberationLine`） | 月の勝ちを一行で。n は FINALE.nodes − 自分の拠点数 |
| （なし） | **島の解放まで · 採掘場か中継塔** | 16 に届いても発着場の隣が無いと決戦は開かない |
| （なし・リザルト） | **島の解放まで · 拠点 あと {前} → {後}** | その日の攻め・守りが目標をどう動かしたか |
| 前線／探索（決戦の日の出撃の目的） | **決戦 · 発着場** | 今日の作戦と同じ。departure の抜けを修正 |
| （一語の印・信号所） | **リザルトと同じ文**（`Profile.news` 最大 10） | 控えを永続化。予告（noticed）は出さない |
| （なし・お隣を攻めた行） | **{お隣}の{拠点}を取った／攻めきれなかった**（`newsIncursion`） | 精算の `Settlement.incursion` を画面で使う |
| トロフィー 1,030 → 1,000 | **トロフィー {前} → {後}（取った +{a} · 取られた −{b}）**（`trophyLine`） | 前後だけでは理由が分からない |
| （なし・勝ちの取り消し） | **{拠点}の勝ちが取り消された · トロフィー −{n}** | 知らせなしにトロフィーが戻らないようにする |
| （なし・起動時の防衛ログ） | **島の知らせ**（一枚の見出し。本文はリザルトと同じ文） | 留守中の対人を一度だけ。履歴は信号所 |

### 「段を上げる」の検討（判断記録）

| 案 | 長所 | 短所 |
| --- | --- | --- |
| 段を上げる（「次の」だけ削る） | 既存に近い | 「段」が初見で不明のまま |
| **レベルを上げる（採用）** | 初見で通じる。SoT 一箇所 | 英語由来 |
| 育てる | 「拠点が育つ」と韻 | +1 段階か曖昧 |

異論があれば `TERM.raiseLevel` を一行戻すだけでよい。

### 「送る」→「遠征に出す」→ボタン廃止（判断記録）

| 段階 | 扱い |
| --- | --- |
| 送る → 遠征に出す | 来る遠征と対。画面語として採用済み（スタック） |
| E4 採用後 | 信号所ボタンは**置かない**。攻めは地図の **攻める** |
| 取り返す → 攻める | 同じ動作。語を寄せる |

### 「攻める」の検討

| 案 | 長所 | 短所 |
| --- | --- | --- |
| **攻める（採用）** | 出撃・前線と同じ線。取り返すと一本 | 「守る」と対で通じやすい |
| 取り返すのまま | 既存 | 「自分の拠点を戻す」に聞こえ、攻め先ゼロで詰む |

## 開発者向け

- 新しいプレイヤー向け文字列 → `TERM` / `PHRASE` に追加 → UI から参照 → この表に 1 行
- `BANNED` に足した語は UI ソースに生で書けない
- 採用した同義語は `PENDING_SYNONYMS` から `BANNED` へ移す
- 「送る」は exact match のみ禁止（`倉庫へ送る` ⊂ 含まない）— `scripts/ringfall-copy-lint.ts`
