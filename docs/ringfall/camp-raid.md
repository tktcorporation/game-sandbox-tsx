## なぜ変えるか

いまの体験は「気持ちよさ」以前に、流れとして成立していない。原因は細部ではなく骨組みにある。

1. **一人用の脱出シューターの上に、CoC 型の取り合いを重ねている。** 倉庫・商人・貴重品・持ち帰りは「漁って生きて帰る」ための仕組みで、対人はその上に後から乗った。
2. **一回の出撃に目的が三つある。** 箱を漁って持ち帰る／ロボットの前線を押す（核）／お隣の外側の拠点を取る（トロフィー・部隊戦の力）。CoC は「攻める」一回で資源もトロフィーも入り、行動と結果が一本に揃う。RINGFALL では三つが時間と全滅のリスクを奪い合い、何を優先すればよいか分からない。
3. **育てる場所と攻められる場所が違う。** 育てるのは野営地（メニュー）、攻められるのは外側の拠点（レイドの中でしか見えない）、その間をつなぐ「工場の部隊が守っている」は見えない。「自分の場所が主役」が空間の作りで崩れている。
4. **「お隣が自分の島の前線に立つ」が想像しにくい。** 相手の場所へ行かず、自分の島にある相手の拠点を取る。誰かを攻めている実感が薄く、「前線」がロボットとの前線とお隣との取り合いの二つの意味を持つ。
5. **出口が三本ある。** 普段のレイド、別マップの部隊戦、自動の守り。削って一本の線に寄せても、骨組みが三本のままなのでつながらない。

## 決定

**自分の島（ロボット相手）で漁って野営地を育て、他の人の野営地へ攻めに行く。自分の野営地の守りは自動。**

野営地を CoC の村に当てる。育てる場所＝攻められる場所＝自分で守りに手を入れる場所、を一つにする。

| | 漁り（島） | 攻め（お隣の野営地） |
| --- | --- | --- |
| 行き先 | 自分の島の 4 地域（いまのレイドのまま） | お隣の**野営地**（相手が育てた設備・工場の部隊） |
| 敵 | ロボット（敵・はぐれ） | 相手の工場の部隊と設備（自動で戦う） |
| 持ち帰る | 貴重品・材料（設備を作る素材） | 相手の倉庫の一部＋トロフィー |
| 長さとリスク | 長い。全滅で荷物を失う（脱出の緊張） | 短い（5 分前後が目安）。失うのは持ち込んだ物だけ |
| 育つもの | 作業場・工場のレベル | トロフィー・リーグ |

一文のループ:

```
島で漁る → 野営地を育てる（＝他の人から見た攻め先と自分の守りが強くなる）
        → お隣の野営地を攻める → 物資とトロフィー → また育てる
留守中 … 自分の野営地が攻められ、工場の部隊と設備が勝手に守る → 結果は島の知らせ → やり返す
```

出撃の入口は**門のまま一つ**。出撃地図に「島の地域」と「お隣の野営地」が並び、選んだ先で漁りか攻めかが決まる。新しい名詞は足さない（攻め先は「{誰}の野営地」）。

## いまの仕組みの扱い

| いまの仕組み | 扱い |
| --- | --- |
| 外側の拠点の取り合い（お隣が自分の島の前線に立つ・作り順②） | **外す。** 島の拠点はロボットとの前線だけに戻し、「前線」の意味を一つにする |
| 守り中／今日取られた n/1（作り順③） | 野営地が攻められたあとの**盾**に付け替える（CoC のシールド） |
| 4 人チーム（作り順④） | 残す |
| 部隊戦・荒地の戦場（作り順⑤⑥） | **相手チームの野営地を攻め合う戦い**に置き換える（CoC のクラン対戦と同型）。別マップは要らなくなる |
| 島の知らせ・やり返す・偵察・トロフィー・リーグ | そのまま、野営地への攻めに付け替える |
| 工場の部隊 | 自分の野営地の**守備隊**として目に見える。攻めに来た相手と戦う |
| 倉庫 | 攻められたとき盗られる量を減らす守り（CoC の資源庫） |
| 島の守り（中継ボックスで積まれる在庫） | 野営地の守りの在庫に寄せるか、外すかを ③ で決める |
| AI の島 | **AI の野営地**に作り替える（人が少ないあいだの攻め先・攻めてくる相手） |
| 島の Worker（`IslandDO`）・遠征の自動解決 | 解決の対象を「拠点」から「野営地」へ移して流用する |

作り順②〜⑥の外側の取り合い・部隊戦の場のコードは、置き換えが終わった段で**コードごと削除**する（`FEATURES` は使わない。復活は Git 履歴から）。

## 作り順

各段は流れが一周するところまで作り、遊んで確かめてから次へ進む。

1. **AI の野営地を一つ攻められる最小版。** 野営地の地図を流用し、門の出撃地図から攻め先に選べる。攻める → 結果 → 倉庫に届く → 野営地が育つ、が一周する。外側の取り合いはこの段では触らない
2. **自分の野営地が攻められる（自動の守り）。** 留守中に AI が攻め、工場の部隊と設備が守り、結果が島の知らせに出て、やり返すで ① へ戻れる
3. **資源の分け方と持ち込みの数字**（未決 3・4）を sim で決める
4. **本物のお隣**（`IslandDO` の解決対象を野営地へ）。トロフィーの組み合わせをここへつなぐ
5. **外側の取り合いと荒地の戦場を削除**し、部隊戦を野営地の攻め合いに置き換える
6. **守りの配置の編集**（未決 1 の後半）
