# RINGFALL brief

## 誰のための何か

バトロワの「降下して、拾って、撃ち合って、リングに追われる」流れは好きだが、対人戦で負け続けるのは楽しくない人向けの、1 人用シューター。相手は全員ロボットで、動きと攻撃の予兆が読める。エイムが下手でも、動き回って撃ち続ければ前に進める。

## 目的

空から島へ降下し、3 つの拠点のロボット部隊を順に制圧する。拠点を落とすたびにリングが次の拠点へ縮む。最後に発着場のボス「タイタン」を倒し、ドロップシップで生還する。1 周 6〜8 分。画面には常に「次に何をするか」と「そこまでの距離」だけを出す。

## 雰囲気（3 語）

爽快 / 疾走感 / 戦利品がうれしい

## 下手でも気持ちいい仕組み

- エイムアシストは sim 側にある。照準が敵の近くにあると感度が落ち、移動しながら撃つと照準が敵へ寄り、狙いが外れていても一定の角度内なら弾が敵に当たる。クリティカルだけは補正前の素の照準で判定する（上手さの差を残すため）
- 戦術アビリティ（Q）は狙わなくても前方の敵を最大 4 体まで自動で撃ち抜き、予兆中の攻撃を止める
- アルティメット（Z）は 8 秒間、弾が減らず、連射が速く、アシストが最大になる
- 敵を倒すとシールドの欠片が吸い寄せられて回復する。撃ち続けることが回復になる
- HP が尽きても、拠点ごとに 1 回は自己蘇生できる。全滅してもその拠点の入口から、持ち物と倒した敵はそのままでやり直せる
- 敵の弾は遅く、大きく、マゼンタに光る。撃つ前に必ず光って溜める

## 手触りの指定（数値）

- 命中: 白いヒットマーカー 80ms。弱点命中は黄色 + 高い音
- ダメージ数字: 命中位置から浮かぶ。敵のシールドに当たった数字はシールドの色、本体に当たった数字は白
- シールド破壊: 破片 + ガラスの割れる音 + ヒットストップ 50ms
- 撃破: ヒットストップ 40ms、画面揺れ、撃破マーカー 400ms
- 拠点の最後の 1 体: 0.3 倍速のスローを 400ms
- スライディング: 視野角 +8°、ダッシュ中の速度 1.3 倍から 1 秒で減衰。スライディングからのジャンプは勢いを保つ
- 発砲: 反動で視点が 0.3° 跳ね、0.12 秒で戻る

## 見た目の方向

晴れた昼の峡谷。砂色の地面、赤茶の岩、明るい水色の空。人工物はコンクリートの灰白とコンテナの錆色・青緑。敵は濃紺の装甲に赤く光る目（弱点）。敵弾だけがマゼンタ、リングは赤橙。戦利品の色はジャンルの約束どおり白 / 青 / 紫 / 金で、光の柱で遠くから見える。面で塗るローポリ、輪郭線なし、影は落とす。

## 使わないもの

- 黒地にネオンのシアンとマゼンタ、グリッドの床（シンセウェーブ調）。マゼンタは敵弾だけに使う
- 発光（ブルーム）の多用。光るのは敵の目・敵弾・戦利品の柱だけ
- ドット絵フォント、等幅フォントのラベル、「01 / 02 / 03」の番号見出し
- 説明文の段落。操作はタイトルに短く並べるだけ
- 実在のゲームの名前・キャラクター・武器名

## 完了の条件

`npm run build`、`npm run sim:ringfall`（3 段階の腕前のボットが全員完走する）、`npm run shots:ringfall`（実ブラウザで最後まで遊び、コンソールエラー 0）の 3 つが通り、スクリーンショットを見て上の「見た目の方向」と矛盾がないこと。
