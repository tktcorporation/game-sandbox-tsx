# RINGFALL の難度曲線

`npm run sim:ringfall -- 30` の出力と対で更新する。3 段階の腕前のボット（`src/ringfall/sim/bot.ts`）が降下から生還までを遊ぶ。腕前の差は、照準の揺らぎ（標準偏差 6.5° / 3.2° / 1.1°）、振り向きの速さ、反応の遅れ、予兆を見て避ける確率、弱点を狙うかどうか。

## 目標

| 腕前 | 完走 | ダウン / 周 | 弱点命中率 | 同時に戦う数（crowd） |
| ---- | ---- | ----------- | ---------- | --------------------- |
| 初心者 | 100%（全滅しても拠点の入口から続けられる） | 0.1〜0.5 | 15〜25% | 3 部隊 / 8 体以下 |
| 普通 | 100% | 0.2 以下 | 15〜25% | 3 部隊 / 8 体以下 |
| 上手い | 100% | ほぼ 0 | 40% 以上 | 3 部隊 / 8 体以下 |

狙いは、下手でも最後まで行けて、腕前の差がタイムと弱点命中率に出ること。flank は命中のうち背後と奇襲の割合。ボットの回り込みは人より下手で、腕前の差を測る指標として見る。crowd は 1 周のうち最も多くの部隊・ロボットと同時に戦った瞬間の値（タイタン戦を除く）で、拠点を部隊ごとに片付けられているかの指標。命中率はアシストで全員 80% 以上になる。上手さは「当たるか」ではなく「弱点に当たるか」と「速く片付くか」で見せる。

ボットは迷わず、探索もしないので、人が遊ぶ時間の下限にあたる。ランクの基準タイム（`RANK.parSeconds` = 240 秒、25% 超過ごとに 1 段階下がる）は人のプレイ時間（5〜7 分）に合わせてあり、ボットは全員 S になる。

ボットは地上の経路探索（`src/ringfall/sim/nav.ts`、0.5 m 格子の A*）で建物のドアを通り、壁を回り込む。屋上や高台には登らない。屋上の敵が真上の縁で隠れたときは、14 m 離れて角度を取る。

## 数値と効き方

| 数値 | 値 | 効き方 |
| ---- | -- | ------ |
| アシストの角度（`ASSIST.hipCone` / `adsCone`） | 2.6° / 3.6° | 体の外を撃っても当たる範囲。5.5° では全腕前で命中率 94〜100% になり、腕前の差が消えた |
| 照準の吸い寄せ（`ASSIST.pull`） | 1.6 / 秒 | 移動しながら撃つか覗いているときだけ効く。止まって撃つと効かないので、動くことが得になる |
| タッチ操作の吸い寄せ（`ASSIST.touchPull`） | 1.6 倍、止まっていても効く | 親指 1 本では照準と横移動を同時にしにくい。ボットはマウス扱いなので、上の表の結果には入らない |
| 弱点の判定 | 補正前の素の照準 | アシストで当たった弾は必ず体に当たる扱い。弱点命中率が腕前の指標として残る |
| 単発武器の押しっぱなし（`SEMI_HOLD`） | 間隔 1.3 倍で連射 | クリックし直す必要があると、押しっぱなしにする人は 1 発しか撃てない |
| 敵弾の速さ | 13〜23 m/s | 15 m 先から 0.7 秒以上かかる。予兆の最後 35% で狙いが固定されるので、横に動けば避けられる |
| タイタンの追尾（`TITAN.homing`） | 0.55 rad/s | 1.2 では横移動で振り切れず、初心者ボットがボス戦で 14 回ダウンした |
| 高所の敵 | 各拠点に 1〜2 部隊 | 屋上・櫓・塔の上に配置。歩く敵は 1 m を超える段差から降りない（`enemies.ts` の `LEDGE`）ので、その場に留まって上から撃つ |
| 島の広さ（`WORLD.half`） | 150 m（300 m 四方） | 拠点間は 120〜190 m。ボットの 1 周は約 3 分半で、人の 6〜8 分の下限にあたる |
| リングの縮小時間（`RING.shrinkTime`） | 45 秒 | 拠点間が 190 m あり、30 秒ではリングの移動に走りが追いつかない |
| 同時に戦う部隊（`AWARE.maxSquads`） | 2 | 制限なしでは銃声と外れ弾で拠点の全部隊が加わり、同時に 3〜6 部隊・最大 11 体と戦っていた |
| 必ず加わる距離（`AWARE.joinClose`） | 5 m | 回り込みの途中で隣の部隊の近くを通ると、8 m では中継塔で 3 部隊目が加わってダウンした |
| 銃声の届く距離（`NOISE`） | 16〜34 m（PIKE 26 m） | 40 m では 1 発で拠点の全部隊が調べに来た |
| アシストの優先順位 | 気づいていない敵を後回し | アシストで外れ弾が眠っている部隊に当たり、交戦の連鎖の最大の原因になっていた |
| グラント / ドローンの弾のダメージ | 11 / 13 | 部隊ごとの戦いになって被弾が減り、9 / 11 では初心者もダウン 0 になった |
| 撃破時のシールド欠片（`PLAYER.shardShield`） | 8 | 消耗を残し、1 部隊を片付けるたびに立て直す間を作る |
| グラントの攻撃間隔 | 1.8 秒 | 正面の弾が 0.75 倍になって撃ち合いが長くなり、1.5 秒では全腕前でダウン 0.4〜0.6 になった |
| 向きによるダメージ（`FLANK.mult`） | 正面 0.75 / 横 1 / 背後 2 / 奇襲 2.5 | 正面 0.6 では正面で撃ち合うボットが全腕前でダウン 0.4〜0.6 になった。背後 1.5 では回り込みにかかる時間を取り返せず、上手いボットが最も遅かった |
| 交戦中の視界（`AWARE.engagedFov` / `engagedRange`） | 幅 1.2 倍 / 距離 1.6 → 1.25 倍 | 1.4 倍・1.6 倍では交戦中の部隊が 77% の時間プレイヤーを追えて、回り込んでも正面になった |
| 振り向きの速さ（`TURN`） | グラント 2.4 rad/秒、ヘビー 1.3 rad/秒 | 一瞬で振り向くと背後が取れない |
| 撃てる向き（`AWARE.fireCone`） | 正面 ±25° | 横や背後へ弾を出せると、回り込む間に撃たれ続ける |
| 遮蔽物の散布（`map.ts` の `scatterCover`） | 12 m 間隔の格子に約 400 個 | 固定の乱数で置き、建物・部隊の持ち場・巡回路・補給箱から離す |
