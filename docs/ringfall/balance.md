# RINGFALL の難度曲線

`npm run sim:ringfall -- 30` の出力と対で更新する。3 段階の腕前のボット（`src/ringfall/sim/bot.ts`）が降下から生還までを遊ぶ。腕前の差は、照準の揺らぎ（標準偏差 6.5° / 3.2° / 1.1°）、振り向きの速さ、反応の遅れ、予兆を見て物陰に入る確率、押されたときに視線を切って下がる確率、回り込む確率、弱点を狙うかどうか。

ボットは人と同じルールで遊ぶ。気づかれる前のロボット（調べに来るロボットを含む）には止まってしゃがみ、スナイパーで先に撃つ。戦いは近くの低い遮蔽の後ろから撃ち、予兆が見えたらしゃがむ。2 体に見られたときやシールドが割れたときは、見られずに行ける物陰へ下がり、見失わせてから回復し、横か後ろから戻る。回り込みは 1 部隊だけと戦っていて見ているのが 1 体以下のときに限る。レイダーが降りたら予定の拠点を半分で切り上げ、自己蘇生を使い切ったか、傷を負って回復アイテムが無いときも脱出へ向かう。脱出は静かな廃村を選ぶ。呼んで待つ脱出地点では、傷を負っていれば呼ぶ前に回復し、呼んだ後は降りてくる部隊から見えない近くの物陰で待ち、迎えが着いてから乗り込む。待つ間は離脱ジャンプを使わない。

## 目標

| 腕前 | 生還（alive） | 制圧する拠点（cleared） | ダウン / 周 | 弱点命中率 | 同時に戦う数（crowd） | 背後と奇襲（flank） |
| ---- | ------------- | ----------------------- | ----------- | ---------- | --------------------- | ------------------- |
| 初心者 | 85% 以上 | 2 | 0.5 以下 | 指標にしない | 2 部隊・4 体以下 | 指標にしない |
| 普通 | 70〜85% | 2〜3 | 1 以下 | 15〜25% | 2 部隊・4 体以下 | 15% 以上 |
| 上手い | 85〜95% | 3〜4 | 0.5 以下 | 40% 以上 | 2 部隊・4 体以下 | 25% 以上 |

正面からの撃ち合いは、1 体なら勝てて、2 体以上なら負けるようにしてある。初期の PIKE で正面の胴を撃ち続けるとグラントは 1.9 秒で倒れるが、ロボットは横へ走りながら撃ち、弾は速く先を狙い、居座ると部隊に挟まれる。2 体に正面を見せると、倒す前に倒される。生き残るのは、先に見つけて先に撃ち、物陰から撃ち、押されたら視線を切って下がる遊び方で、flank はその割合を測る。制圧する拠点の数は欲張りすぎない引き際を含めた目標で、レイダーが降りた後も粘る遊び方は生還率が下がる。

ロボットは数発でプレイヤーを倒す強さにしてあり、拠点を多く回るほど全滅の危険が上がる。全滅の大半は、4 分後に降りるレイダーとの戦いと、2 つ目の拠点で起きる。

全滅するとレイドは終わり、スコアは 0 になる。ボットは腕前ごとに制圧する拠点の数を決めてから脱出する（`bot.ts` の `Skill.raid`：初心者 2、普通 4、上手い 4）が、上の引き際で切り上げることが多い。近い順に回り、タイタンは他の拠点をすべて制圧した後にだけ狙う。タイタンまで行く周が少ないので、弱点の大きいタイタンで稼ぐ弱点命中がなく、体を狙う初心者と普通の弱点命中率は低く出る。

味方（リオ）は、与ダメージの 1〜2 割を担い、交戦中のロボットの 15% 前後に狙われる程度に留める。主役はプレイヤーのままにし、味方は攻撃を散らして、全滅の手前で拾い上げる役にする。ally 列は、与ダメージに占める割合、1 周あたりのダウン（d）、プレイヤーを起こした回数（r）、プレイヤーに起こされた回数（h）。

脱出地点は降下した時点から開いている。ドロップシップが最も早く（呼んで 20 秒、増援と戦う）、廃村が最も遅く静か（15 秒待つ）になるように置く。台地は発煙筒があれば最も早く静かだが、ボットは高い建物に登らないので使わない（`checkFlareExtract` が別に確かめる）。exit 列は、各地点から脱出した周の数。ボットは初心者と、タイタンが残っているときと、レイダーが降りた後は廃村を選び、それ以外はドロップシップを選ぶ。

スコアは、生還したときの回収の価値（8 種類、ヒューズ 60〜小型炉心 2200、`config.ts` の `VALUABLES`）と、制圧した拠点 1 つにつき 400 点、タイタン 1500 点の合計。ランクは S 4500 / A 3000 / B 1500 点以上（`config.ts` の `SCORE`）。

カバン（`BAG.slots`）は 10 枠で、回収品は 1〜4 枠を取る。haul の中央値は枠で頭打ちになる。補給箱から出る回収品の種類は拠点ごとの重み（`map.ts` の `POIS[].loot.valuable`）で決まる。補給箱は調べるのに 2.2 秒（最上階 3.5 秒）かかり、9 m 先まで音が届く（`SEARCH`）。

増援（`REINFORCE`）は着地 3 分後に最初の部隊が、以後 2 分ごとに次が降りる。レイダー（`RAIDERS`）は着地 4 分後、戦闘が途切れたところで 1 度だけ降りる。タイタン戦の最中はどちらも降りない。waves 列はレイド中に降りた増援の数。ボットは迷わず探索もしないので 2〜4 分で島を出て、増援に会うのは 0〜1 回になる。人は寄り道と箱漁りで 10〜15 分かかり、4〜6 回の増援に追われる想定で、長居するほど危なくなる。

アルティメットは離脱ジャンプ（`ULT`）。ゲージは与ダメージと 150 秒の時間経過で溜まり、真上へ約 26 m 跳んで滑空し、別の場所へ降りる。ボットは体力とシールドが 4 割を切り、2 体以上と交戦しているときに、ロボットから最も遠い開けた低地（建物の近くと、途中に高い建物がある向きは選ばない）へ跳ぶ。leap 列は 1 周あたりの使用回数。

狙いは、欲張らなければ生きて帰れて、欲張るほど危なくなり、腕前の差が持ち帰る価値と弱点命中率に出ること。flank は命中のうち背後と奇襲の割合。ボットの回り込みは人より下手で（2 部隊目に見られる道を選ぶと倒れるので、1 部隊相手にしか回り込まない）、腕前の差を測る指標として見る。crowd は 1 周のうち最も多くの部隊・ロボットと同時に戦った瞬間の値（タイタン戦を除く）。命中率はアシストで全員 80% 前後以上になる。上手さは「当たるか」ではなく「弱点に当たるか」と「どれだけ持ち帰れるか」で見せる。

## 隠れ家の進み方（目標）

`npm run sim:ringfall` の最後に、ゲートのボットが遊んだレイドを腕前ごとに順に精算し直し、隠れ家を作り進める（`scripts/ringfall-pacing.ts`）。使い方は単純な貪欲法で、依頼の納品を済ませ、作れる段のうち最も安い段（足りない材料は、商人が売っていれば買い足す）を作り、何にも要らない回収品と装備を売る。倉庫には 1 レイド分（カバンの枠数）の空きを残し、足りなければ、どの設備の次の段にも要らない回収品を、余っている種類から売る。降下地域は、その地域のレイドが平均で何クレジット分持ち帰るか（隠れ家がまだ要り、商人が売っていない回収品は 2 倍に数える）と、出ている制圧の依頼で選ぶ。

| 腕前 | 脱出艇を直すまで |
| ---- | ---------------- |
| 上手い | 25〜40 レイド |
| 普通 | 40〜70 レイド |

どの段も上手いと普通のボットが 200 レイド以内に作れること。どの段の材料も、補給箱か保管庫から出ること（`checkHideout`）。

目標から外れている値:

- ダム湖の生還は初心者 93%、普通 43%、上手い 60% で、初心者は目標（85% 以上）に入り、普通と上手いは目標（70〜85%、85〜95%）を下回る。撃ち合いの手触りを変える前（初心者 60%、普通 67%、上手い 50%）から普通と上手いは目標の下にあった。普通の 67% → 43% は、30 周ずつの生還率のぶれ（乱数の引き方だけで 10% 前後）を超える。普通の命中率は、エイムアシストの円錐を狭めて 80% から 73% に下がった。敵の数と配置を変えるマップの拡張と合わせて、難度はまとめて合わせ直す
- ダウンは初心者 0.1、普通 1.2、上手い 0.8 で、普通と上手いが目標を超える（変える前は 1.0 / 0.9 / 1.1）
- flank は普通 19%、上手い 24% で、普通は目標（15% 以上）に入り、上手いは目標（25% 以上）をわずかに下回る。ヘビーとレイダーの奇襲が 1.5 倍になっても、背後と奇襲の命中の割合は下がらなかった
- 弱点命中率は普通 4%、上手い 27% で、目標（15〜25%、40% 以上）を下回る。タイタンまで行く周が少なく、大きな弱点で稼ぐ命中がない
- 港湾地帯の生還は 60% / 60% / 53% で、変える前（40% / 33% / 37%）より上がった。港湾の出口はボートだけで、呼んで 25 秒待つ間に降りてくる部隊と戦う。残る全滅はレイダー戦と、塩田と拠点の高所から撃たれる戦い

30 周ずつの生還率は、乱数の引き方だけで 10% 前後ぶれる。

ボットは地上の経路探索（`src/ringfall/sim/nav.ts`、0.5 m 格子の A*）で建物のドアを通り、壁と崖を回り込み、坂道を通る。崖は下りにも使わない。峡谷の橋は使わず、放水路の谷底を回る。よじ登りは使わず、床や屋上にある補給箱は狙わない。階段で床に上がってしまったときは、歩いた跡をたどって地面へ戻る。屋上の敵が真上の縁で隠れたときは、14 m 離れて角度を取る。

## 数値と効き方

| 数値 | 値 | 効き方 |
| ---- | -- | ------ |
| 照準の吸い寄せ（`ASSIST.pull`） | 1.6 / 秒 | 覗いているときだけ効く（動いていても止まっていても）。腰だめで撃ちながら動いても効かない。狙って撃つ 1 発を助け、横に動きながらの撃ち合いは助けない |
| タッチ操作の吸い寄せ（`ASSIST.touchPull`） | 1.6 倍、腰だめで撃っている間も効く | 親指 1 本では照準と横移動を同時にしにくい。ボットはマウス扱いなので、上の表の結果には入らない |
| 弱点の判定 | 補正前の素の照準。体と弱点のうち手前に当たった方 | アシストで当たった弾は必ず体に当たる扱い。弱点命中率が腕前の指標として残る。背後から体越しに向こう側の弱点は撃ち抜けない |
| 単発武器の押しっぱなし（`SEMI_HOLD`） | 間隔 1.3 倍で連射 | クリックし直す必要があると、押しっぱなしにする人は 1 発しか撃てない |
| タイタンの追尾（`TITAN.homing`） | 0.55 rad/s | 1.2 では横移動で振り切れず、初心者ボットがボス戦で 14 回ダウンした |
| 高所の敵 | 各拠点に 1〜2 部隊 | 屋上・櫓・塔の上に配置。歩く敵は 1 m を超える段差から降りない（`enemies.ts` の `LEDGE`）ので、その場に留まって上から撃つ |
| 歩ける範囲（`terrain.ts` の `BASINS` / `ROADS` / `LEVEL`） | 段 6 つ（採掘場 -10 m、湖底 -7 m、岸 0 m、尾根 +5 m、東の台地 +7 m、ダム +8 m）、盆地 11 か所と道 13 本、道の幅 8〜10 m、坂は 1 m あたり 0.45 m 以下 | 登れない高地（17〜22 m）が残りを占める。拠点ごとに入口を 2〜3 本に絞り、どの坂から入るかを選ばせる。段の縁の崖は飛び降りられるが登れないので、湖底は入りやすく出にくい |
| 降下の風（`DROP.drift`） | 26 m/s | 高地の上では操作が効かず、近い歩ける地面へ運ばれる。降下で高地に降りることはない |
| 崖の傾き（`STEEP`）と崖の止め（`geom.ts` の `CLIFF_GRIP`） | 1 m あたり 1 m（45°）より急。足より 5 cm 以上高い崖のマスには立てない | 高地の壁・段の縁・島の縁は登れない。坂道、岩棚、放水路の坂は歩いて登れる |
