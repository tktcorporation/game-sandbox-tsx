# RINGFALL の難度曲線

`npm run sim:ringfall -- 30` の出力と対で更新する。3 段階の腕前のボット（`src/ringfall/sim/bot.ts`）が、地域の入口から生還までを遊ぶ。各周は地域の入口を順に使う（周 `r` は `r` を入口の数で割った余りの入口）。各周は増援の追跡に使う距離場（`hunt.ts`）を持ち越さずに始まる（`newRun()`）ので、周の結果はシードだけで決まり、ゲートがどのプロセスでどの順に遊んでも変わらない。腕前の差は、照準の揺らぎ（標準偏差 6.5° / 3.2° / 1.1°）、振り向きの速さ、反応の遅れ、予兆を見て物陰に入る確率、押されたときに視線を切って下がる確率、回り込む確率、弱点を狙うかどうか。

ボットは人と同じルールで遊ぶ。気づかれる前のロボット（調べに来るロボットを含む）には止まってしゃがみ、スナイパーで先に撃つ。戦いは近くの低い遮蔽の後ろから撃ち、予兆が見えたらしゃがむ。2 体に見られたときやシールドが割れたときは、見られずに行ける物陰へ下がり、見失わせてから回復し、横か後ろから戻る。回り込みは 1 部隊だけと戦っていて見ているのが 1 体以下のときに限る。レイダーが降りたら予定の拠点を半分で切り上げ、自己蘇生を使い切ったか、傷を負って回復アイテムが無いときも脱出へ向かう。脱出は静かな廃村を選ぶ。呼んで待つ脱出地点では、傷を負っていれば呼ぶ前に回復し、呼んだ後は降りてくる部隊から見えない近くの物陰で待ち、迎えが着いてから乗り込む。待つ間は離脱ジャンプを使わない。

## 目標

| 腕前 | 生還（alive） | 制圧する拠点（cleared） | ダウン / 周 | 弱点命中率 | 同時に戦う数（crowd） | 背後と奇襲（flank） |
| ---- | ------------- | ----------------------- | ----------- | ---------- | --------------------- | ------------------- |
| 初心者 | 70% 以上 | 2 | 1 以下 | 指標にしない | 2 部隊・4 体以下 | 指標にしない |
| 普通 | 55〜75% | 2〜3 | 1.5 以下 | 15〜25% | 2 部隊・4 体以下 | 15% 以上 |
| 上手い | 75〜90% | 3〜4 | 1 以下 | 40% 以上 | 2 部隊・4 体以下 | 25% 以上 |

正面からの撃ち合いは、1 体なら勝てて、2 体以上なら負けるようにしてある。初期の PIKE で正面の胴を撃ち続けるとグラントは 1.9 秒で倒れるが、ロボットは横へ走りながら撃ち、弾は速く先を狙い、居座ると部隊に挟まれる。2 体に正面を見せると、倒す前に倒される。生き残るのは、先に見つけて先に撃ち、物陰から撃ち、押されたら視線を切って下がる遊び方で、flank はその割合を測る。制圧する拠点の数は欲張りすぎない引き際を含めた目標で、レイダーが降りた後も粘る遊び方は生還率が下がる。

ロボットは数発でプレイヤーを倒す強さにしてあり、拠点を多く回るほど全滅の危険が上がる。全滅の多くは、拠点を回り終えて島を出る前後に、12 分後に降りるレイダーや増援と戦う周で起きる。

全滅するとレイドは終わり、スコアは 0 になる。ボットは腕前ごとに制圧する拠点の数を決めてから脱出する（`bot.ts` の `Skill.raid`：初心者 2、普通 4、上手い 3）が、上の引き際で切り上げることもある。近い順に回り、タイタンは他の拠点をすべて制圧した後にだけ狙う。上手いの予定の 3 拠点は、ダム湖ではタイタンを除く 3 拠点になるので、上手いはタイタンと戦わない。普通は 4 拠点を予定するが、引き際で切り上げる周が多く、タイタンまで行く周は少ない。弱点の大きいタイタンへの命中は弱点命中率を押し上げるので、タイタンと戦う周が減ると弱点命中率が下がる。

味方（リオ）は、与ダメージの 1〜2 割を担い、交戦中のロボットの 15% 前後に狙われる程度に留める。主役はプレイヤーのままにし、味方は攻撃を散らして、全滅の手前で拾い上げる役にする。ally 列は、与ダメージに占める割合、1 周あたりのダウン（d）、プレイヤーを起こした回数（r）、プレイヤーに起こされた回数（h）。

脱出地点はレイドの始めから開いている。ドロップシップが最も早く（呼んで 20 秒、増援と戦う）、廃村が最も遅く静か（15 秒待つ）になるように置く。台地は発煙筒があれば最も早く静かだが、ボットは高い建物に登らないので使わない（`checkFlareExtract` が別に確かめる）。exit 列は、各地点から脱出した周の数。ボットは初心者と、タイタンが残っているときと、レイダーが降りた後は廃村を選び、それ以外はドロップシップを選ぶ。

スコアは、生還したときの回収の価値（8 種類、ヒューズ 60〜小型炉心 2200、`config.ts` の `VALUABLES`）と、制圧した拠点 1 つにつき 400 点、タイタン 1500 点の合計。ランクは S 4500 / A 3000 / B 1500 点以上（`config.ts` の `SCORE`）。

カバン（`BAG.slots`）は 10 枠で、回収品は 1〜4 枠を取る。haul の中央値は枠で頭打ちになる。補給箱から出る回収品の種類は拠点ごとの重み（`map.ts` の `POIS[].loot.valuable`）で決まる。補給箱は調べるのに 2.2 秒（最上階 3.5 秒）かかり、9 m 先まで音が届く（`SEARCH`）。

増援（`REINFORCE`）はレイドの始めから 4 分半後に最初の部隊が、以後 3 分 45 秒ごとに次が降りる。レイダー（`RAIDERS`）はレイドの始めから 12 分後、戦闘が途切れたところで 1 度だけ降りる。タイタン戦の最中はどちらも降りない。waves 列はレイド中に降りた増援の数。ボットは迷わず探索もしないので、ダム湖は入口から 6〜11 分、港湾は 4〜5 分で地域を出て、増援に会うのは 1〜2 回になる。人は寄り道と箱漁りでダム湖に 15〜22 分かかり、3〜5 回の増援に追われる想定で、長居するほど危なくなる。

アルティメットは離脱ジャンプ（`ULT`）。ゲージは与ダメージと 150 秒の時間経過で溜まり、真上へ約 26 m 跳んで滑空し、別の場所へ降りる。ボットは体力とシールドが 4 割を切り、2 体以上と交戦しているときに、ロボットから最も遠い開けた低地（建物の近くと、途中に高い建物がある向きは選ばない）へ跳ぶ。leap 列は 1 周あたりの使用回数。

狙いは、欲張らなければ生きて帰れて、欲張るほど危なくなり、腕前の差が持ち帰る価値と弱点命中率に出ること。flank は、タイタンを除く命中のうち、背後からと奇襲の割合。奇襲は、気づかれる前の命中と、交戦中でも自分ではまだプレイヤーを見つけていないロボット（`awareness.ts` の `located()`）への最初の命中。タイタンは向きに関係なく同じダメージを受けるので数えない。ボットの回り込みは人より下手で（2 部隊目に見られる道を選ぶと倒れるので、1 部隊相手にしか回り込まない）、腕前の差を測る指標として見る。crowd は 1 周のうち最も多くの部隊・ロボットと同時に戦った瞬間の値（タイタン戦を除く）。命中率はアシストで全員 80% 前後以上になる。上手さは「当たるか」ではなく「弱点に当たるか」と「どれだけ持ち帰れるか」で見せる。

## 隠れ家の進み方（目標）

`npm run sim:ringfall` の最後に、ゲートのボットが遊んだレイドを腕前ごとに順に精算し直し、隠れ家を作り進める（`scripts/ringfall-pacing.ts`）。使い方は単純な貪欲法で、依頼の納品を済ませ、作れる段のうち最も安い段（足りない材料は、商人が売っていれば買い足す）を作り、何にも要らない回収品と装備を売る。倉庫には 1 レイド分（カバンの枠数）の空きを残し、足りなければ、どの設備の次の段にも要らない回収品を、余っている種類から売る。出撃する地域は、その地域のレイドが平均で何クレジット分持ち帰るか（隠れ家がまだ要り、商人が売っていない回収品は 2 倍に数える）と、出ている制圧の依頼で選ぶ。

| 腕前 | 脱出艇を直すまで |
| ---- | ---------------- |
| 上手い | 25〜40 レイド |
| 普通 | 40〜70 レイド |

どの段も上手いと普通のボットが 200 レイド以内に作れること。どの段の材料も、補給箱か保管庫から出ること（`checkHideout`）。

目標から外れている値:

- ダム湖の普通と上手いの crowd は 2 部隊・5 体で、目標（4 体以下）を 1 体超える。同時に戦うのは 2 部隊までなので、5 体は 3 体以上の部隊（中継塔の機器棟、2 波目以降の増援、レイダー）を含む瞬間になる。拠点に加えた部隊はどれも 2 体にしてある。
- ダム湖の弱点命中率は普通 7%、上手い 21% で、目標（15〜25% / 40% 以上）を下回る。タイタン以外のロボットへの弱点命中率と同じ水準で、タイタンと戦う周がほとんど無いことによる。上手いは予定の 3 拠点にタイタンを含まず、普通は引き際で切り上げる周が多い。
- 上手いが脱出艇を直すまでのレイド数は 68 で、目標（25〜40）を超える。拠点 1 つで戦う部隊が倍になり、上手いは 1 レイドに 3 拠点しか回らず、データコアが出る発着場とタイタン（データコア 2 個）へ行かない。普通は 82 で、目標（40〜70）を超える。どちらも 30 周の乱数の引き方で 30 レイド前後動く（下の「隠れ家の進み方」）。
- 港湾地帯の生還は初心者 37%、普通 57%、上手い 63% で、目標を置いていないが、どの腕前もダム湖の目標の下限を下回る。ダウンは 2.0 / 1.4 / 1.0。
- ダム湖の生還は初心者 83%、普通 53%、上手い 57% で、普通と上手いは目標（55〜75% / 75〜90%）を下回る。全滅は 5 周、14 周、13 周。ダウンは 0.9、1.2、1.1。道ができて遮蔽物が道沿いに寄り、道から離れた野が開けたこと、湖畔の町の見回りが環状の道に立つこと、補給所の北と東がフェンスで閉じたことが重なる。

目標に入っている値:

- 30 周ずつの生還率は乱数だけで 10% 前後ぶれる。
- ダム湖の制圧する拠点の中央値は初心者 1、普通 2、上手い 3 で、普通と上手いは目標（2〜3 / 3〜4）に入り、初心者は目標（2）を 1 下回る。
- flank は普通 26%、上手い 28%。港湾地帯は 7% / 14% / 21%。港湾の出口はボートだけで、呼んで 25 秒待つ間に降りてくる部隊と戦う。
- ダム湖の初心者の crowd は 2 部隊・4 体。

両地域の野に落ちた環の残骸（`RING_WRECKS`）を横たえ、越えられる所を切れ目・トンネル・斜めの桁・瓦礫の山に限った。ダム湖の生還は初心者 83%（77%）、普通 53%（60%）、上手い 57%（60%）、港湾地帯は 37%（40%）、57%（57%）、63%（60%）で、30 周の乱数のぶれの範囲で動いた。

野に道（`STREETS`）を通し、遮蔽物を道沿いに寄せて道から離れた野を開け、湖底の南岸に見回りの部隊（2 体）のいる町（`TOWN_FRAMES`）を建て、コンテナヤード・製錬所・補給所の北と東をフェンス（`FENCES`）で閉じた。開始時のロボットはダム湖 52 体。ロボットはフェンス越しに見えた相手へ門を回って向かう。ダム湖の生還は初心者 77%（80%）、普通 60%（70%）、上手い 60%（77%）、ダウンは 1.0 / 1.0 / 1.0（0.6 / 0.7 / 0.7）で、難しくなった。

拠点の間に小拠点を置き（`OUTPOSTS`。港湾に変電所、燃料基地、貨物操車場、荷揚げ場、保線基地の 5 つ、ダム湖に東の変電所と揚水ポンプ場の 2 つ）、それぞれに 2 体の守備隊と補給箱 2 個を持たせた。開始時のロボットはダム湖 50 体（46 体）、港湾地帯 47 体（37 体）。守備隊は塀の内側や建物を向き、拠点の間を通りがかるだけでは見つかりにくい。港湾の最初の 3 つを置いた段階で港湾の生還を 60 周で比べると、初心者 35%（32%）、普通 35%（35%）、上手い 62%（68%）で、乱数のぶれの範囲に収まった。

拠点の部隊を増やし（`POIS[].squads`）、交戦中の視界の外から撃たれた部隊が撃ち返すようにした（`RETURN`）ことで、表は次のように動いた（変える前の値を括弧に書く）。発着場を除く各拠点に 2 体の部隊を 2 つずつ加え、拠点は 4 部隊・8〜9 体（2 部隊・4〜5 体）になった。加えた部隊はグラントとドローンの組が多く、中継塔の南東の縁はドローン 2 機、難破船の舳先はチャージャーとドローンで、コンテナヤードの東の列は巡回する。開始時のロボットは、ドローンの群れと遊撃隊を含めてダム湖 46 体（34 体）、港湾地帯 37 体（25 体）。同時に戦う部隊は 2 つまで（`AWARE.maxSquads`）のままで、拠点は 1〜2 部隊ずつ片付けて進む場所になる。撃ち返しは、撃たれたロボットの交戦中の視界（グラント 56 m、ヘビー 52 m）より遠くからの命中にだけ効き、その部隊は命中のたびに 7 秒、グラントとヘビーが 140 m 先まで見つけて撃つ（`fireRange()`）。視線の通らない仲間は撃たれた場所へ向かって歩き、ドローンとチャージャーは寄ってくる。上手いのボットの予定は 3 拠点（4 拠点）にした:

- 遠くからの弾の命中（ロボットをその場に留め、2 秒ごとに撃って撃ち返しを続けさせる。4 シードで 20 秒ずつ）：グラントの 1 発あたりの命中は、立ち止まる相手に 40 m 16%、56 m 7%、90 m 4%、130 m 4%。0.9 秒ごとに左右へ向きを変えて歩く相手に 14%、6%、2%、1%。ヘビーの散弾は 90 m 以上では当たらない。遠くからの撃ち返しは、ほとんど外れ、ときどき当たり、物陰へ追いやる程度なので、弾のそれ（`SHOT.spread`、1.5°）は変えていない。
- シミュレーションのゲート（`checkReturnFire`）：開けた所で 90 m と 130 m 離れ、横を向いて持ち場にいるグラント 2 体の部隊の 1 体を撃つと、4 秒以内に部隊の誰かが撃ち返す。撃たない部隊は 130 m 先のプレイヤーに 8 秒たっても気づかない。撃ち返しを切ると、90 m の部隊は 4 秒たっても撃たず、79 m まで歩いて寄る。
- 生還：ダム湖の初心者 87%（83%）、普通 63%（67%）、上手い 80%（83%）。港湾は初心者 40%（53%）、普通 33%（73%）、上手い 63%（87%）。
- ダウン：ダム湖の初心者 0.7（0.5）、普通 1.2（0.9）、上手い 0.6（0.5）。港湾は 1.8（1.2）、1.7（1.0）、1.2（0.7）。
- 制圧する拠点：ダム湖の上手い 3（4）。弱点命中率：普通 6%（13%）、上手い 20%（39%）。
- 戦った部隊（1 周あたり）：ダム湖の初心者 8.4（5.4）、普通 13.3（9.3）、上手い 15.1（12.0）。最初の戦いまでの秒数は普通 17 秒（29 秒）、上手い 13 秒（29 秒）。

ボットは地上の経路探索（`src/ringfall/sim/nav.ts`、0.5 m 格子の A*）で建物のドアを通り、壁と崖を回り込み、坂道を通る。崖は下りにも使わない。峡谷の橋は使わず、放水路の谷底を回る。よじ登りは使わず、床や屋上にある補給箱は狙わない。階段で床に上がってしまったときは、歩いた跡をたどって地面へ戻る。建物の中で格子の閉じたマス（階段の脇など）に立っているときは、壁越しではなく見通せる開いたマスから経路を引く。屋上の敵が真上の縁で隠れたときは、14 m 離れて角度を取る。A* の見積もりには、拠点の中央と脱出地点を目印にした歩行距離を使い、タイタンの視界を回る探索ではタイタンの持ち場を回る歩行距離を使う。どちらも真の道のりを超えないので、道は最短のまま。ボットは目的地が 3 m 動くか、次の曲がり角へまっすぐ歩けなくなるか、2 秒近づけないときに道を引き直す。

## 測った重さ

4 コアの共有の開発機で測った値。ここの値は、世界が東西 900 m・南北 1690 m（`WORLD`）、広げる前（560 m・965 m）の 2.8 倍の面積だったときに測った。いまは補給所を建て直して南北 1880 m（広げる前の 3.1 倍）になっている。

| ---- | -- | -------- |
| 地形の構築（`buildTerrain()`、1 m 格子） | 2.1〜2.4 秒 | 0.72〜0.87 秒 |
| 遮蔽物の配置（`scatterCover()`） | 61〜183 ms | 43〜51 ms |

ダム湖の拠点を実物の大きさにした後（世界は東西 1200 m・南北 1880 m、箱の数は 12582）、`npm run sim:ringfall -- 30` は 1948 秒かかった。共有の機械で他の作業と重なった中で測った値で、上の値とは比べられない。

ボットの経路探索（A*）と追跡の距離場の構築を型付き配列で組み直し、ゲートが表ではなく周を単位にワーカーへ配るようにした後、`npm run sim:ringfall -- 30` は 554 秒になった（同じ機械で他の重い作業が無いときに測り、組み直す前は 1744 秒）。表を単位に配ると、ダム湖の上手いの表（30 周で約 15 分）を遊ぶワーカーが最後まで残った。

A* の見積もりに目印からの歩行距離を使い、ボットが道を使えるうちは引き直さないようにし、追跡の距離場と遮蔽の候補探しを軽くした後、`npm run sim:ringfall -- 30` は 291 秒になった。同じ機械で続けて測った変更前は 861 秒で、CPU 時間はユーザー 2969 秒・システム 221 秒が 932 秒・117 秒になった。`-- 10` は 325 秒が 160 秒。この機械は時間帯で重さが大きく変わり、変更前のゲートが 2063 秒かかった時間帯もあるので、比べるときは続けて測る。ワーカーは最初の周で目印の距離場と経路探索の格子を作り、その周は後の周より CPU 時間が 30〜40 秒多い。うち 20 秒ほどはシステム時間で、新しいメモリのページに初めて触れるときの例外による。ゲートはダム湖の周を港湾の周より先に配るので、最後に残るのは短い周になる。

目印の距離場を、全格子の大きさの 2 組（平らな歩行とタイタンの持ち場を回る歩行、確保は 1 プロセスで約 400 MB）から、行ごとに届いたマスの区間だけを詰めた形にし、戦いで道なしに動いた後は道を引き直すようにした後、`npm run sim:ringfall -- 30` は 218 秒（続けて測った直前の版は 243 秒）。5 周を遊ぶプロセスで、型付き配列の確保は 576 MB が 330 MB、RSS は 553 MB が 441 MB、目印の場 17 枚は 137 MB になった。ゲートの 4 つのワーカーの最大 RSS は 545〜559 MB が 546〜568 MB で、45 周を遊ぶワーカーの最大は場の大きさでは決まっていない。
