# RINGFALL の難度曲線

`npm run sim:ringfall -- 30` の出力と対で更新する。3 段階の腕前のボット（`src/ringfall/sim/bot.ts`）が降下から生還までを遊ぶ。腕前の差は、照準の揺らぎ（標準偏差 6.5° / 3.2° / 1.1°）、振り向きの速さ、反応の遅れ、予兆を見て避ける確率、弱点を狙うかどうか。

## 目標

| 腕前 | 生還（alive） | 制圧する拠点（cleared） | ダウン / 周 | 弱点命中率 | 同時に戦う数（crowd） |
| ---- | ------------- | ----------------------- | ----------- | ---------- | --------------------- |
| 初心者 | 90% 以上 | 2 | 0.5 以下 | 指標にしない | 2 部隊・4 体以下 |
| 普通 | 75〜90% | 3〜4 | 1 以下 | 15〜25% | 2 部隊・4 体以下 |
| 上手い | 85〜95% | 4 | 0.5 以下 | 40% 以上 | 2 部隊・4 体以下 |

ロボットは数発でプレイヤーを倒す強さにしてあり、拠点を多く回るほど全滅の危険が上がる。普通と上手いのボットはタイタンの近くのドロップシップから出るため、タイタン戦とレイダーで倒れる周がある。

全滅するとレイドは終わり、スコアは 0 になる。ボットは腕前ごとに制圧する拠点の数を決めてから脱出する（`bot.ts` の `Skill.raid`：初心者 2、普通 4、上手い 4）。近い順に回り、タイタンは他の拠点をすべて制圧した後にだけ狙う。初心者はタイタンと戦わないので、弱点の大きいタイタンで稼ぐ弱点命中がなく、弱点命中率は低く出る。

味方（リオ）は、与ダメージの 1〜2 割を担い、交戦中のロボットの 15% 前後に狙われる程度に留める。主役はプレイヤーのままにし、味方は攻撃を散らして、全滅の手前で拾い上げる役にする。ally 列は、与ダメージに占める割合、1 周あたりのダウン（d）、プレイヤーを起こした回数（r）、プレイヤーに起こされた回数（h）。

脱出地点は降下した時点から開いている。ドロップシップが最も早く（呼んで 20 秒、増援と戦う）、廃村が最も遅く静か（15 秒待つ）になるように置く。台地は発煙筒があれば最も早く静かだが、ボットは高い建物に登らないので使わない（`checkFlareExtract` が別に確かめる）。exit 列は、各地点から脱出した周の数。ボットは初心者が廃村、ほかがドロップシップを選ぶ。

スコアは、生還したときの回収の価値（8 種類、ヒューズ 60〜小型炉心 2200、`config.ts` の `VALUABLES`）と、制圧した拠点 1 つにつき 400 点、タイタン 1500 点の合計。ランクは S 4500 / A 3000 / B 1500 点以上（`config.ts` の `SCORE`）。

カバン（`BAG.slots`）は 10 枠で、回収品は 1〜4 枠を取る。haul の中央値は枠で頭打ちになる。補給箱から出る回収品の種類は拠点ごとの重み（`map.ts` の `POIS[].loot.valuable`）で決まる。補給箱は調べるのに 2.2 秒（最上階 3.5 秒）かかり、9 m 先まで音が届く（`SEARCH`）。

増援（`REINFORCE`）は着地 3 分後に最初の部隊が、以後 2 分ごとに次が降りる。レイダー（`RAIDERS`）は着地 4 分後、戦闘が途切れたところで 1 度だけ降りる。タイタン戦の最中はどちらも降りない。waves 列はレイド中に降りた増援の数。ボットは迷わず探索もしないので 2〜4 分で島を出て、増援に会うのは 0〜1 回になる。人は寄り道と箱漁りで 10〜15 分かかり、4〜6 回の増援に追われる想定で、長居するほど危なくなる。

アルティメットは離脱ジャンプ（`ULT`）。ゲージは与ダメージと 150 秒の時間経過で溜まり、真上へ約 26 m 跳んで滑空し、別の場所へ降りる。ボットは体力とシールドが 4 割を切り、2 体以上と交戦しているときに、ロボットから最も遠い開けた低地（建物の近くと、途中に高い建物がある向きは選ばない）へ跳ぶ。leap 列は 1 周あたりの使用回数。

狙いは、欲張らなければ生きて帰れて、欲張るほど危なくなり、腕前の差が持ち帰る価値と弱点命中率に出ること。flank は命中のうち背後と奇襲の割合。ボットの回り込みは人より下手で、腕前の差を測る指標として見る。crowd は 1 周のうち最も多くの部隊・ロボットと同時に戦った瞬間の値（タイタン戦を除く）。命中率はアシストで全員 80% 前後以上になる。上手さは「当たるか」ではなく「弱点に当たるか」と「どれだけ持ち帰れるか」で見せる。

## 隠れ家の進み方（目標）

`npm run sim:ringfall` の最後に、ゲートのボットが遊んだレイドを腕前ごとに順に精算し直し、隠れ家を作り進める（`scripts/ringfall-pacing.ts`）。使い方は単純な貪欲法で、依頼の納品を済ませ、作れる段のうち最も安い段（材料の安い物は商人から買い足す）を作り、何にも要らない回収品と装備を売る。降下地域は、隠れ家がまだ要る回収品をその地域のレイドが平均で何クレジット分持ち帰るかと、出ている制圧の依頼で選ぶ。

| 腕前 | 脱出艇を直すまで |
| ---- | ---------------- |
| 上手い | 25〜40 レイド |
| 普通 | 40〜70 レイド |

どの段も上手いと普通のボットが 200 レイド以内に作れること。どの段の材料も、補給箱か保管庫から出ること（`checkHideout`）。

- 上手い（good）は中央値 36 レイドで脱出艇を直し、目標（25〜40）に入る。
- 普通（casual）は中央値 31 レイドで、目標（40〜70）より早い。普通のボットは上手いのボットと同じだけ生還し（ダム湖 83%、港湾 83〜87%）、ダム湖ではジャイロと記憶装置を多く持ち帰るため、材料の数では差が付かない。差は、ボットのレイドの結果（生還と持ち帰る物）が腕前で分かれて初めて出る。
- 初心者（beginner）は脱出艇の制御系（Lv3）から先に進まない。近い 2 拠点しか回らず、タイタンも倒さないので、データコアを持ち帰らない。それ以外の段はすべて作る。
- ボットは貸出装備で降り、拾った装備をすべて売るので、クレジットは序盤の数レイドを過ぎると足止めにならない。

全体の数値（`config.ts`）は 2 地域で共通にしてある。広い世界での手触りは人が遊んで確かめ、そのうえで地域ごとの調整を決める。

30 周ずつの生還率は、乱数の引き方だけで 10% 前後ぶれる。

ボットは地上の経路探索（`src/ringfall/sim/nav.ts`、0.5 m 格子の A*）で建物のドアを通り、壁と崖を回り込み、坂道を通る。崖は下りにも使わない。峡谷の橋は使わず、放水路の谷底を回る。よじ登りは使わず、床や屋上にある補給箱は狙わない。階段で床に上がってしまったときは、歩いた跡をたどって地面へ戻る。屋上の敵が真上の縁で隠れたときは、14 m 離れて角度を取る。

## 数値と効き方

| 数値 | 値 | 効き方 |
| ---- | -- | ------ |
| 照準の吸い寄せ（`ASSIST.pull`） | 1.6 / 秒 | 移動しながら撃つか覗いているときだけ効く。止まって撃つと効かないので、動くことが得になる |
| タッチ操作の吸い寄せ（`ASSIST.touchPull`） | 1.6 倍、止まっていても効く | 親指 1 本では照準と横移動を同時にしにくい。ボットはマウス扱いなので、上の表の結果には入らない |
| 弱点の判定 | 補正前の素の照準。体と弱点のうち手前に当たった方 | アシストで当たった弾は必ず体に当たる扱い。弱点命中率が腕前の指標として残る。背後から体越しに向こう側の弱点は撃ち抜けない |
| 単発武器の押しっぱなし（`SEMI_HOLD`） | 間隔 1.3 倍で連射 | クリックし直す必要があると、押しっぱなしにする人は 1 発しか撃てない |
