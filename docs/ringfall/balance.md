# RINGFALL の難度曲線

`npm run sim:ringfall -- 30` の出力と対で更新する。3 段階の腕前のボット（`src/ringfall/sim/bot.ts`）が降下から生還までを遊ぶ。腕前の差は、照準の揺らぎ（標準偏差 6.5° / 3.2° / 1.1°）、振り向きの速さ、反応の遅れ、予兆を見て避ける確率、弱点を狙うかどうか。

## 目標

| 腕前 | 生還（alive） | 制圧する拠点（cleared） | ダウン / 周 | 弱点命中率 | 同時に戦う数（crowd） |
| ---- | ------------- | ----------------------- | ----------- | ---------- | --------------------- |
| 初心者 | 90% 以上 | 2 | 0.5 以下 | 指標にしない | 2 部隊・4 体以下 |
| 普通 | 75〜90% | 3〜4 | 1 以下 | 15〜25% | 2 部隊・4 体以下 |
| 上手い | 85〜95% | 4 | 0.5 以下 | 40% 以上 | 2 部隊・4 体以下 |

ロボットは数発でプレイヤーを倒す強さにしてあり、拠点を多く回るほど全滅の危険が上がる。普通と上手いのボットはタイタンの近くのドロップシップから出るため、タイタン戦とレイダーで倒れる周がある。

全滅するとレイドは終わり、スコアは 0 になる。ボットは腕前ごとに制圧する拠点の数を決めてから脱出する（`bot.ts` の `Skill.raid`：初心者 2、普通 4、上手い 4）。近い順に回り、タイタンは他の拠点をすべて制圧した後にだけ狙う。初心者はタイタンと戦わないので、弱点の大きいタイタンで稼ぐ弱点命中がなく、弱点命中率は低く出る。

味方（リオ）は、与ダメージの 1〜2 割を担い、交戦中のロボットの 15% 前後に狙われる程度に留める。主役はプレイヤーのままにし、味方は攻撃を散らして、全滅の手前で拾い上げる役にする。ally 列は、与ダメージに占める割合、1 周あたりのダウン（d）、プレイヤーを起こした回数（r）、プレイヤーに起こされた回数（h）。

脱出地点は降下した時点から開いている。ドロップシップが最も早く（呼んで 20 秒、増援と戦う）、廃村が最も遅く静か（15 秒待つ）になるように置く。台地は発煙筒があれば最も早く静かだが、ボットは高い建物に登らないので使わない（`checkFlareExtract` が別に確かめる）。exit 列は、各地点から脱出した周の数。ボットは初心者が廃村、ほかがドロップシップを選ぶ。

スコアは、生還したときの回収の価値（部品 100、回路基板 300、データコア 1000）と、制圧した拠点 1 つにつき 400 点、タイタン 1500 点の合計。ランクは S 4500 / A 3000 / B 1500 点以上（`config.ts` の `SCORE`）。

カバン（`BAG.slots`）は 10 枠で、部品 1・回路基板 2・データコア 3 枠を取る。haul の中央値は枠で頭打ちになる。補給箱は調べるのに 2.2 秒（最上階 3.5 秒）かかり、9 m 先まで音が届く（`SEARCH`）。

増援（`REINFORCE`）は着地 3 分後に最初の部隊が、以後 2 分ごとに次が降りる。レイダー（`RAIDERS`）は着地 4 分後、戦闘が途切れたところで 1 度だけ降りる。タイタン戦の最中はどちらも降りない。waves 列はレイド中に降りた増援の数。ボットは迷わず探索もしないので 2〜4 分で島を出て、増援に会うのは 0〜1 回になる。人は寄り道と箱漁りで 10〜15 分かかり、4〜6 回の増援に追われる想定で、長居するほど危なくなる。

狙いは、欲張らなければ生きて帰れて、欲張るほど危なくなり、腕前の差が持ち帰る価値と弱点命中率に出ること。flank は命中のうち背後と奇襲の割合。ボットの回り込みは人より下手で、腕前の差を測る指標として見る。crowd は 1 周のうち最も多くの部隊・ロボットと同時に戦った瞬間の値（タイタン戦を除く）。命中率はアシストで全員 80% 前後以上になる。上手さは「当たるか」ではなく「弱点に当たるか」と「どれだけ持ち帰れるか」で見せる。

弱点命中率（crit）は普通 14%、上手い 37% で、目標（15〜25%、40% 以上）をわずかに下回る。

ボットは地上の経路探索（`src/ringfall/sim/nav.ts`、0.5 m 格子の A*）で建物のドアを通り、壁と崖を回り込み、坂道を通る。崖は下りにも使わない。峡谷の橋は使わず、放水路の谷底を回る。よじ登りは使わず、床や屋上にある補給箱は狙わない。階段で床に上がってしまったときは、歩いた跡をたどって地面へ戻る。屋上の敵が真上の縁で隠れたときは、14 m 離れて角度を取る。

## 数値と効き方

| 数値 | 値 | 効き方 |
| ---- | -- | ------ |
| 照準の吸い寄せ（`ASSIST.pull`） | 1.6 / 秒 | 移動しながら撃つか覗いているときだけ効く。止まって撃つと効かないので、動くことが得になる |
| タッチ操作の吸い寄せ（`ASSIST.touchPull`） | 1.6 倍、止まっていても効く | 親指 1 本では照準と横移動を同時にしにくい。ボットはマウス扱いなので、上の表の結果には入らない |
| 弱点の判定 | 補正前の素の照準。体と弱点のうち手前に当たった方 | アシストで当たった弾は必ず体に当たる扱い。弱点命中率が腕前の指標として残る。背後から体越しに向こう側の弱点は撃ち抜けない |
| 単発武器の押しっぱなし（`SEMI_HOLD`） | 間隔 1.3 倍で連射 | クリックし直す必要があると、押しっぱなしにする人は 1 発しか撃てない |
| タイタンの追尾（`TITAN.homing`） | 0.55 rad/s | 1.2 では横移動で振り切れず、初心者ボットがボス戦で 14 回ダウンした |
| 高所の敵 | 各拠点に 1〜2 部隊 | 屋上・櫓・塔の上に配置。歩く敵は 1 m を超える段差から降りない（`enemies.ts` の `LEDGE`）ので、その場に留まって上から撃つ |
| 歩ける範囲（`terrain.ts` の `BASINS` / `ROADS` / `LEVEL`） | 段 6 つ（採掘場 -10 m、湖底 -7 m、岸 0 m、尾根 +5 m、東の台地 +7 m、ダム +8 m）、盆地 11 か所と道 13 本、道の幅 8〜10 m、坂は 1 m あたり 0.45 m 以下 | 登れない高地（17〜22 m）が残りを占める。拠点ごとに入口を 2〜3 本に絞り、どの坂から入るかを選ばせる。段の縁の崖は飛び降りられるが登れないので、湖底は入りやすく出にくい |
| 降下の風（`DROP.drift`） | 26 m/s | 高地の上では操作が効かず、近い歩ける地面へ運ばれる。降下で高地に降りることはない |
| 崖の傾き（`STEEP`）と崖の止め（`geom.ts` の `CLIFF_GRIP`） | 1 m あたり 1 m（45°）より急。足より 5 cm 以上高い崖のマスには立てない | 高地の壁・段の縁・島の縁は登れない。坂道、岩棚、放水路の坂は歩いて登れる |
| 平らに保つ範囲（`buildTerrain`） | 手で置いた物から 3 m、そこから 7 m で地形に戻す | 建物・持ち場・巡回路・補給箱の高さが変わらない |
| よじ登りの届く高さ（`MANTLE.reach`） | 足元から 1.9 m | ジャンプと合わせて約 2.9 m。建物 1 階分（3.4 m）に届くと、屋上の見張りへ階段なしで回れてしまう |
| スナイパー TALON（`WEAPONS.talon`） | 90 / 弱点 2 倍、間隔 1.2 秒、5 発、スコープ 18°、銃声 30 m | 初期装備。気づかれる前に遠くから 1 体ずつ減らせる。音が大きいので、撃つと隣の見張りを起こす |
| 回復アイテム（`HEALS`） | セル +25 / 1.2 秒、バッテリー全快 / 2.4 秒、注射器 +25 / 1.4 秒、医療キット全快 / 3.0 秒 | 小さい方は早く、大きい方は長く無防備になる。戦闘の合間にどれを使うかを選ぶ |
| 坂でのスライディング（`PLAYER.slideSlope` / `slideMax`） | 重力の 0.7 倍 / 最高 15 m/s | 坂を滑り降りると加速する |
| 岩棚（`SHELVES`） | 拠点ごとに 1 本、高さ 3.4 m、奥行き 8 m | 拠点の脇を上から回る道。登り口は片方の端の坂だけ |
| 地上の見張りが登れる高さ（`enemies.ts` の `CLIMB`） | 地面から 1.2 m | 外階段で屋根に上がったチャージャーが降りられず、拠点を落とせなくなった |
| 敵弾のダメージ | グラント 20、ドローン 21、ヘビー 18、チャージャー 40（以前の約 1.3 倍） | 正面で撃ち合うと数発でシールドが割れる。回り込みと先手が要る |
| 敵弾の速さ | 以前の 1.2 倍 | 予兆を見てから動いても、遠目でないと避けきれない |
| プレイヤーのシールド（`PLAYER.shieldByTier`） | 25 / 50 / 75 / 100 | アーマーを拾う価値を上げる。初期の 25 では 2 発で割れる |
| 体力の自然回復の上限（`PLAYER.regenCap`） | 30 | 戦闘の合間に回復アイテムを使わせる |
| エイムアシストの角度（`ASSIST.hipCone` / `adsCone`） | 2.1° / 2.9° | 当てやすさを少し下げ、撃ち合いを長くする |
| 撃てる向き（`AWARE.fireCone`） / 振り向き（`TURN`） | ±40° / グラント 3.0、ヘビー 1.6 rad/秒 | 回り込みの途中でも撃たれる。背後を取るには速く大きく回る |
| 正面からの弾（`FLANK.mult.front`） | 0.85 | 正面で削れなくはないが、背後（2 倍）との差は大きい |
| レイダー（`RAIDERS` / `ELITE`） | 3 体、体力 1.6 倍、弾 1.3 倍、振り向き 1.5 倍、±70° に撃つ、左右 11 m へ回り込む、4 秒ごとに居場所を知り直す | 長居への最大の罰。隠れずに押してきて、横から撃たれる |
| 同時に戦う部隊（`AWARE.maxSquads`） | 2 | 巡回部隊と増援が駆けつけて戦いに加わる。1 では寄ってきた部隊が「?」のまま待つだけで、敵の動きが小さく見えた。3 部隊目以降は加わらない |
| 巡回部隊（`map.ts` の `ROAMERS` の `roam`） | 谷道 4 本、2〜3 体ずつ | 道を往復する。銃声が `NOISE.roamMult`（2.5 倍）遠くまで届き、撃ち合いに寄ってくる。待ち伏せと横槍で、拠点だけを見ていればよい状態を崩す |
| 増援（`REINFORCE`） | 着地 3 分後から 2 分ごと、プレイヤーから歩いて 55〜110 m（`hunt.ts` の距離場で測る坂と道の道のり）の見えない低地。最初の一歩の区間にロボットが越えられない箱（0.45 m 超）を挟まない場所を優先する。距離場は崖・高地・越えられない箱のマスを閉じる。相手が見えない間は、交戦中でも距離場をたどって坂を登り、建物を回り込む。見えたらまっすぐ向かう | 2〜4 体で 4 段階に強くなる。長居の代償。人の想定レイド（10〜15 分）で 4〜6 回。見つけるまで 8 秒ごとにプレイヤーの居場所を知り直して寄ってくる。常に追うと隠れても逃げられない |
| 価値のある物（`VALUABLES` と `LootTable.valuable`） | 補給箱 1 つにつき 1 個。近い拠点は部品、遠い拠点は回路基板、高い建物の最上階は 4 割でデータコア。ロボットは 3 割で部品、ヘビーは回路基板、タイタンはデータコア 2 個 | 危ない場所ほど高い物が出て、寄り道する理由になる |
| 地上から高所を撃てる場所（`bot.ts` の `angleSpot`） | 40 m 以内で胴が見える地上の地点のうち、歩いて最も近い所 | 時計塔の見張りは 34 m 以上離れた数か所からしか見えない。14 m まで下がるだけでは撃ち返せず、リオが何度も倒れた |

| 見張りの配置（`map.ts` の `POIS[].squads`） | 拠点ごとに 6 体、ほぼ 1 体ずつ | 2〜3 体の部隊を 4 つ固めると、拠点に着いた時点で全部が見えた。2 階や高い屋根の中は地上から倒せず、拠点を落とせなくなるので置かない |
| 視界の距離（`SIGHT`） | グラント 30 m、ヘビー 28 m、ドローン 26 m | 近づくまで気づかれず、1 体ずつ先手を取れる |
| 必ず加わる距離（`AWARE.joinClose`） | 5 m | 回り込みの途中で隣の部隊の近くを通ると、8 m では中継塔で 3 部隊目が加わってダウンした |
| 銃声の届く距離（`NOISE`） | 10〜22 m（PIKE 16 m） | 26 m では 1 体を撃つたびに隣の見張りが調べに来た |
| 味方の腕前（`ALLY.dmg` / `hitNear` / `hitFar`） | 1 発 11、6 発ずつ、命中 80%（近距離）〜30%（48 m） | 与ダメージは全体の 13〜19%。プレイヤーの PIKE の 4 分の 1 ほどの火力 |
| 味方への狙いやすさ（`ALLY.aggroBias`） | 1 m 遠い扱い、味方に撃たれたロボットは 4 m 近い扱い | 6 m では狙われるのが 1 割で、味方がいる手応えがなかった。1 m で 15〜17% |
| 味方が撃つ相手 | 交戦中のロボットだけ | 気づいていない見張りを撃つと、忍び寄りと先手の奇襲が成り立たなくなる |
| ドロップシップ（`EXTRACTS` の call / `SHIP_WAVES`） | 呼んで 20 秒、4.5 秒ごとに 2 体ずつ 4 回、同時に最大 5 体 | 30 秒・7 秒ごとでは、静かな廃村（31 秒）より遅く、選ぶ理由がなかった。20 秒で 25〜26 秒、廃村は 34 秒 |
| 廃村の待ち時間 | 15 秒 | 遠いが静かな道。ドロップシップより遅くなるように置く |
| アシストの優先順位 | 気づいていない敵を後回し | アシストで外れ弾が眠っている部隊に当たり、交戦の連鎖の最大の原因になっていた |
| ロボットの体力（`ENEMIES`） | グラント 140 + 70、ヘビー 300 + 150、チャージャー 120 + 50、ドローン 70 | 1 体ずつの戦いでは、元の体力だと撃ち返す前に倒れ、全腕前でダウン 0 だった |
| 撃破時のシールド欠片（`PLAYER.shardShield`） | 8 | 消耗を残し、1 部隊を片付けるたびに立て直す間を作る |
| グラントの攻撃間隔 | 1.5 秒 | 相手が 1 体ずつになったので、1 体あたりの圧を上げる |
| 交戦中の視界（`AWARE.engagedFov` / `engagedRange`） | 幅 1.2 倍 / 距離 1.6 → 1.25 倍 | 1.4 倍・1.6 倍では交戦中の部隊が 77% の時間プレイヤーを追えて、回り込んでも正面になった |
| 遮蔽物の散布（`map.ts` の `scatterCover`） | 12 m 間隔の格子に約 400 個 | 固定の乱数で置き、建物・部隊の持ち場・巡回路・補給箱から離す |
