# 他プレイヤー拠点の戦利品（CoC 型）

設計方針（[design-direction.md](design-direction.md)）に沿った、非同期の「他プレイヤーの拠点を攻める／守る」報酬。  
新動詞・特殊キーは増やさない。画面上は既存語のみ（核・制圧・中継ボックス・倉庫・島の守り・攻める）。

関連: [multiplayer.md](multiplayer.md)、[ux-design.md](ux-design.md)、[multiplayer-experience.md](multiplayer-experience.md)。

---

## 何を目指すか

クラッシュ・オブ・クランでは、他人の村を非同期に襲い、守りを突破して資源を持ち帰り、自分の村を育てる。守る側は一部を失い、盾や守りで被害を抑える。

RINGFALL では **他プレイヤーの拠点は前線の一種** とする（方向 A：お隣は自分の島の前線に立つ）。出撃 → 前線で核を制圧 → 持ち帰る → 拠点が育つ、の線に溶かす。

| CoC | RINGFALL（画面上の語） |
| --- | --- |
| 他人の村を襲う | 前線の **お隣の拠点** へ出撃し **核 · 制圧**（攻める） |
| 攻撃勝利のトロフィー | 「攻める」出撃の星（★1–3）→ +N×★/3（物資とは別） |
| 攻撃失敗のトロフィー | 0★ → −M（守り側は +M） |
| 倉庫から資源を取る | **核 · 制圧** → その拠点の **島の守り** が **倉庫へ届く**（空でも多めの控え＋上乗せ） |
| 防衛勝利のトロフィー | **守りきった** → 攻め側の M（知らせとセット） |
| 盾・防衛で被害を抑える | **その日の守り**（取られた拠点はその日は取られない）／**島の盾・喪失上限**（作り順③: 取られたら残り外側も同日中守り・最大 1/日）／新規島の保護／工場と島の守り |
| 戻って被害を見る | 島の知らせ「{誰}に{拠点}を取られた · 島の守りが{誰}の倉庫へ」 |

数値の正本: `TROPHY` / `SEIZE` / `WIN_BONUS` in `src/ringfall/meta/trophies.ts`。[design-direction.md](design-direction.md)「トロフィーは CoC 型」「トロフィーと物資」。

リーグ勝ちボーナス（TKT-219）: 帯ごとに物資 +0..+6 ×★/3。「攻める」出撃のみ（ロボット拠点・部隊戦は対象外）。出撃前に「物資 +n」、リザルトにも。

---

## 攻める側（方向 A・TKT-195）

1. 前線に他プレイヤー保持の拠点がある → 次の一手「{誰}の{拠点}を攻める」。
2. 普段のレイドでその **核** を **制圧**（敵拠点と同じ操作）。別の入口は無い。
3. 精算時（TKT-218）:
   - **トロフィー** — 星で採点（★1 守備の半分／★2 核 · 制圧／★3 制圧して生還）。出撃前に +N / −M を見せる。
   - **物資** — 核 · 制圧で島の守りが **倉庫へ届いた** に載る（空のとき `SEIZE.emptyReserve`、加えて `SEIZE.bonus`。AI も含む）。
4. 島の知らせ「{お隣}の{拠点}を制圧した · トロフィー +n · 倉庫へ届く」（TKT-204 案 E）。リザルトに星行。

ゲート／島なしレイドはライバルも島の守りも持たない → bench hash 不変。

## 守る側（方向 A）

| 状況 | 見えること | 仕組み |
| --- | --- | --- |
| 攻められた（留守） | 「{誰}が{拠点}を攻めた · 守りきった」＋トロフィー行（守りきった +M） | 工場の部隊＋島の守りが守備隊。トロフィーは攻め側の M（知らせとセット） |
| 取られた（留守） | 「{誰}に{拠点}を取られた · 島の守りが{誰}の倉庫へ」＋トロフィー減 | 落ちた拠点の島の守りが相手の倉庫へ。その日はその拠点を取られない |
| 中継ボックスへ送る | 島の守りに回る | 留守の防衛ストック（自動） |

守る動機: 工場を上げる・中継ボックスへ送る → 取られにくく、守りきればトロフィーも少し入る。

攻め側が取れなかったときのトロフィー減は採らない（普段の出撃なので「増えない」が負け）。

---

## 率いる遠征（段階 6）— **廃止**

**廃止済み。** 写し全体での出撃は体験の正から外す。遠い攻めの入口だった短いレイド／○○の前線／遠征に出すも方向 A で削除（TKT-195・PR6）。

| だったもの | いま |
| --- | --- |
| AI 島への率いる出撃 | **やらない** |
| 短いレイド／○○の前線 | **やらない**（PR6 で削除） |
| 写しでの核 · 制圧 | 自分の島の前線の核 · 制圧だけ |

他の人の島へ攻めに行くは **X2（相手島の一部だけの短いレイド）** を実装済み（[game-design-review.md](game-design-review.md) §5.8）。入口は地図の穴 A／攻めるだけ。予告は来る遠征と同じ。実島の結果はサーバーが確定。写し全体の段階 6 は繰り返さない。

## やらないこと

- 「略奪」「物資を奪う」などの新動詞・専用キー
- リアルタイムの対人撃ち合いを前提にする
- ゲートの決定論ハッシュを変える変更
