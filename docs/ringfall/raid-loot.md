# 他プレイヤー拠点の戦利品（CoC 型）

設計方針（[design-direction.md](design-direction.md)）に沿った、非同期の「他プレイヤーの拠点を攻める／守る」報酬。  
新動詞・特殊キーは増やさない。画面上は既存語のみ（核・制圧・中継ボックス・倉庫・島の守り・固める・取り返す）。

関連: [multiplayer.md](multiplayer.md)、[ux-design.md](ux-design.md)。

---

## 何を目指すか

クラッシュ・オブ・クランでは、他人の村を非同期に襲い、守りを突破して資源を持ち帰り、自分の村を育てる。守る側は一部を失い、盾や守りで被害を抑える。

RINGFALL では **他プレイヤーの拠点は前線の一種** とする。出撃 → 前線で核を制圧 → 持ち帰る → 拠点が育つ、の線に溶かす。

| CoC | RINGFALL（画面上の語） |
| --- | --- |
| 他人の村を襲う | 前線の **他プレイヤーの拠点** へ出撃し **核 · 制圧** |
| 倉庫から資源を取る | その拠点の **中継ボックス** に積まれた **島の守り** が **倉庫へ届く** |
| 盾・防衛で被害を抑える | **核 · 固める**（来る遠征をはねる）／新規島の保護／工場と中継ボックスへの送付 |
| 戻って被害を見る | 島の知らせ「取られた · 島の守りが削られた」 |

---

## 攻める側（実装済み・この島での奪還）

1. 前線に他プレイヤー保持の拠点がある → 次の一手「{拠点}を取り返す」。
2. レイドでその **核** を **制圧**（敵拠点と同じ操作）。
3. 精算時、その拠点の中継ボックスにあった島の守りが **倉庫へ届いた** に載る。空なら材料が1点（拠点の備蓄）。
4. トースト「制圧した · {名} · 倉庫へ届く」。

ゲート／島なしレイドはライバルも島の守りも持たない → bench hash 不変。

---

## 守る側（実装済みの一部）

| 状況 | 見えること | 仕組み |
| --- | --- | --- |
| 来る遠征 | 地図の机・次の一手・核 · 固める | 既存 |
| 固めた | 固めた · 来る遠征をはねる | 1日遠征に取られない（盾） |
| 取られた（留守） | 「○に△を取られた · 島の守りが削られた」 | 落ちた拠点の中継ボックス在庫をサーバーが消す |
| 中継ボックスへ送る | 島の守りに回る | 留守の防衛ストック（自動） |

守る動機: 工場を上げる・中継ボックスへ送る・来る遠征を固める → 取られにくく、取られても守りが残る。

---

## 率いる遠征（段階 6）— **廃止（案 A）**

**廃止済み。** [multiplayer-experience.md](multiplayer-experience.md) 案 A により、遠い攻めは信号所の **遠征に出す** だけ。信号所の「出撃」（相手島の写しでレイド）は削除済み。

| だったもの | いま |
| --- | --- |
| AI 島への率いる出撃 | **やらない**。お隣へは **遠征に出す** |
| 写しでの核 · 制圧 | 自分の島の前線／取り返すだけ |
| 人間の島への出撃 | 当初から遠征に出すのみ（変更なし） |

実装残骸や [multiplayer.md](multiplayer.md) の段階表に「率いる」が残っていても、体験の正は案 A。片付けは別 PR。

他の人の島へ攻めに行くは **X2（相手島の一部だけの短いレイド）** を実装済み（[game-design-review.md](game-design-review.md) §5.8）。入口は地図の穴 A／攻めるだけ。予告は来る遠征と同じ。実島の結果はサーバーが確定。写し全体の段階 6 は繰り返さない。
