# HITMARK の難度曲線

`npm run sim -- 30` の出力と対で更新する。3 段階の腕前のボットが全 6 部屋を遊ぶ。腕前の差は照準の誤差（14° / 7° / 2.5°）、反応の遅れ、回避の頻度。

## 目標

| 腕前 | 完走 | ランク | クリティカル率 |
| ---- | ---- | ------ | -------------- |
| 初心者 | 100%（ダウンしても部屋からやり直せる） | B〜C が中心、C は半分以下 | 20〜30% |
| 普通 | 100% | B 中心、A に届く | 35〜45% |
| 上手い | 100% | S が過半 | 70% 以上 |

狙いは、下手でも必ず最後まで進めて当てる手応えがあり、上手くなるとランクとクリティカルで差が見えること。

## 数値と効き方

| 数値 | 値 | 効き方 |
| ---- | -- | ------ |
| 照準補正（`assistPull`） | 0.7 | 当たるかどうかだけを助ける |
| クリティカル判定（`critCore`） | 0.55 | 補正前の素の照準で判定する。補正後の弾道で判定すると、全腕前で 80〜90% になり弱点の意味が消えた |
| 見えない敵の動き | 遮蔽物の角を経由して回り込む | 真っすぐ歩かせると遮蔽物の裏で膠着し、600 秒終わらない部屋が出た |
| ランクの被弾ペナルティ | 4 回で 1 段階 | 2 回で 1 段階では上手いボットでも S が 30 回中 1 回だった |
